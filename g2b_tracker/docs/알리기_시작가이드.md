# 전화 대신 "알리기" 시작 가이드

> 목표: 매일 전화하지 않고, 기관이 **우리를 찾게** 만들기.
> 대표님 일은 아래 **체크리스트 7개(처음 한 번, 반나절)** 와 **문의 응대**뿐입니다. 나머지는 프로그램이 매일 자동으로 합니다.

## 0. 한눈에

| 순서 | 할 일 | 시간 | 효과 |
|---|---|---|---|
| ① | `업데이트.bat` 실행 | 1분 | 오늘 만든 기능 전부 PC에 반영 |
| ② | data.go.kr 에서 **병원정보서비스** 활용신청 | 3분 | 대구·경북 병원 주소록 자동 생성 |
| ③ | open.neis.go.kr 에서 **나이스 인증키** 받기 → `.env` 의 `NEIS_KEY=` 에 붙여넣기 | 5분 | 대구·경북 학교 약 1,400곳 주소록 자동 생성 |
| ④ | `11_우편DM주소록.bat` → **인터넷우체국 e-그린우편**으로 1차 발송 | 30분 | 기관·대학·병원·학교에 우편으로 한 번에 알림 |

| ⑥ | **학교장터(s2b.kr)** 공급업체 가입 | 1~2시간 | 학교 소액 이사 견적요청에 견적서 제출 가능 |
| ⑦ | 텔레그램 알림만 확인 | 매일 1분 | 나라장터 + 학교장터 이사 공고가 자동으로 옴 |

## ② 병원 주소록 열기 (3분)
1. data.go.kr 로그인 (나라장터 API 키 받은 그 계정)
2. 검색창에 **건강보험심사평가원_병원정보서비스** → **활용신청** → 목적: "기관 대상 안내 우편 발송 주소 확인" → 신청 (자동승인)
3. 끝. 키는 지금 쓰는 키 그대로입니다. 승인까지 몇 분~1시간 걸릴 수 있어요.

## ③ 학교 주소록 열기 (5분)
1. open.neis.go.kr → 회원가입 → **인증키 신청** (바로 발급)
2. 받은 키를 `C:\나라장터\g2b_tracker\.env` 파일의 `NEIS_KEY=` 뒤에 붙여넣고 저장
   - 또는 `0_처음설치.bat` 을 다시 실행하면 마지막에 물어봅니다

## ④ 우편 DM 1차 발송 (30분)
1. `11_우편DM주소록.bat` 실행 → `output\우편DM_주소록_날짜.xlsx` 가 생김
2. 엑셀 시트가 **봉투 묶음**입니다

| 시트 | 누구 | 봉투에 넣을 PDF (`docs\우편DM\`) |
|---|---|---|
| `기관1` | 대구시·경북도·구군청, 교육청, 대학 30곳, 혁신도시 공공기관 | `우편DM_기관_간편_1장양면.pdf` |
| `병원1`, `병원2`… | 대구·경북 병원급 이상 (의원 제외) | `우편DM_병원_간편_1장양면.pdf` |
| `학교1`, `학교2`… | 대구·경북 학교 행정실 (메일 이미 받은 곳 제외) | `우편DM_학교_간편_1장양면.pdf` |
| `주소필요` | 주소를 아직 못 넣은 기관 (중구청·동구청 등) | 주소를 채워 `data\dm_extra.csv` 에 넣으면 다음부터 포함 |

3. 인터넷우체국(epost.go.kr) → **e-그린우편** → 로그인
4. 문서: 위 표의 PDF 업로드 (흑백·양면이면 1장)
5. 받는 사람: 시트 내용을 e-그린우편 수신자 엑셀 양식에 붙여넣기 (열 순서: 받는분 · 우편번호 · 주소 · 상세주소)
   - 우편번호가 빈 칸인 기관은 업로드 화면의 **주소 검증**이 알려 줍니다. 틀린 주소로 표시된 줄만 고치세요.
6. 결제 → 우체국이 인쇄·봉투·발송
7. 보낸 뒤 `12_우편DM발송기록.bat` → 보낸 시트 이름(예: `기관1`) 입력 → 다음 주소록에서 빠짐

**추천 순서**: 이번 주 `기관1`(약 60곳) → 반응 보고 다음 주 `병원1` → 12월 초 `학교1`
[업데이트 필요] 요금은 e-그린우편 화면에서 장수·흑백/컬러별로 바로 계산됩니다. 문의 우편고객센터 1588-1300.

## ⑤ 공공구매종합정보망 기업정보 점검 (30분)
여성기업 확인서를 이 사이트(smpp.go.kr)에서 받으셨으니 **회원·기업정보는 이미 있습니다.** 아래만 확인하세요.
1. smpp.go.kr 로그인 → 나의 업무 / 기업정보 관리
2. **확인서 유효기간**: 여성기업·장애인기업·소기업 확인서가 모두 유효한지
3. **주요 제품·서비스**에 아래 문구 넣기 (복사해서 붙여넣기)

```
관공서·학교·병원·기업 사무실/문서고/도서관 이전 전문 (화물자동차 운송주선사업 허가)
- 리모델링·공간재구조화 공사 전 집기 반출 → 100평 직영 실내창고 보관 → 준공 후 재배치까지 일괄
- 실적: 법원 문서고 3만 권 2일 이전, 공공기관 200평 30개 공간 재편, 침대·사무가구 이전설치 5,000건+
- 여성기업·장애인기업 수의계약 가능 / 대구·경북 11년 정직원 팀 / 무료 현장실사
문의 010-2243-7924 · noblesse0913@naver.com
```

4. 나라장터 업체정보의 **세부품명(용역)** 에 이사 관련 품명과 업종 7605가 등록돼 있는지 확인
   (소액 수의계약 견적은 이 세부품명으로 업체를 찾습니다) [업데이트 필요: 정확한 세부품명은 나라장터 콜센터 1588-0800 에 "이사 용역 세부품명"으로 문의]

## ⑥ 학교장터(S2B) 가입 (1~2시간, 한 번)
1. s2b.kr → 회원가입 → **공급자(업체)** → 사업자 공동인증서로 가입
2. 업체 소개·취급 분야에 ⑤의 문구 그대로 사용
3. 가입이 끝나면: 학교가 올린 **견적요청**에 견적서를 낼 수 있습니다
4. 견적요청 찾기는 프로그램이 합니다
   - 매일 자동 실행에 **학교장터 이사·집기 이전 견적요청**이 포함됩니다 (텔레그램·브리핑에 '학교장터'로 표시)
   - 지금 바로 보려면 `14_학교장터추적.bat` (최근 30일)
   - 브리핑의 학교장터 링크는 검색 화면으로 열립니다. **공고번호로 검색**해서 들어가세요.

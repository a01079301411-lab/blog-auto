# 우편 DM 안내

## 왜 우편인가
- 메일은 받는 쪽 동의가 있어야 보낼 수 있지만, **종이 우편은 정보통신망법 대상이 아니라** 공개된 기관 주소로 바로 보낼 수 있습니다.
- 행정실·총무과 책상 위에 실물로 남아 담당자 여러 명이 돌려 봅니다.
- 우편에 "공용 메일을 문자로 보내 주시면 서류를 메일로 드립니다"를 넣어 **우편 → 문자 → 메일 동의**로 이어지게 했습니다.

## 구성 (봉투 1개)
| 파일 | 내용 | 용도 |
|---|---|---|
| `우편DM_표준_편지+제안서4쪽.pdf` | 인사 편지 1쪽 + 제안서 4쪽 = 5쪽 (양면이면 3장) | 대구·근교 우선 대상 |
| `우편DM_간편_1장양면.pdf` | 편지(앞) + 제안서 표지(뒤) = 1장 | 경북 원거리, 비용 줄일 때 |

편지 구조: 받는 사람(행정실·총무·계약) → 제목(겨울방학 공사·조직개편 이사, 견적 업체를 미리 정해 두세요) → 한 문단 소개 → 걱정 3가지 해결 → 실적 숫자 4개 → **CTA: 문자 한 통 (① 공사 시기 → 무료 실사 ② 공용 메일 → 서류 일체)** → P.S. 12월 집중 → 우편 사절 방법

## 주소록 (자동)
1. `.env` 에 `NEIS_KEY` (open.neis.go.kr 무료 인증키) 넣기 — `0_처음설치.bat` 마지막 질문
2. `11_우편DM주소록.bat` → `output\우편DM_주소록_날짜.xlsx`
   - 대구·경북 전체 학교 행정실 (이미 메일 받은 곳, 우편 사절, 이미 보낸 곳 제외)
   - 순서: 대구 → 대구 근교 → 경북 / 고등 → 특수 → 중 → 초
   - 300곳씩 '1차', '2차' … 시트
3. 학교가 아닌 기관을 넣고 싶으면 `data\dm_extra.csv` (열: 받는분, 우편번호, 기본주소, 상세주소, 전화번호)
4. '우편 사절' 문자가 오면 `data\dm_exclude.csv` 에 기관 이름 추가 (또는 Claude 에게 말하기)

## 발송 (인터넷우체국 e-그린우편)
1. 인터넷우체국(epost.go.kr) → 우편 → **e-그린우편** → 사업자 로그인
2. 문서: 위 PDF 업로드 (흑백/컬러, 단면/양면 선택)
3. 받는 사람: 주소록의 '1차' 시트를 e-그린우편 수신자 엑셀 양식에 붙여 넣어 업로드
   (열 이름은 우체국 양식에 맞춰 받는분·우편번호·주소·상세주소만 옮기면 됩니다)
4. 결제 → 우체국이 인쇄·봉투·발송
5. 보낸 뒤 `12_우편DM발송기록.bat` → "1" 입력 → 다음 주소록에서 빠지고 콜리스트 메모에 'DM 발송' 표시

[업데이트 필요] 요금(장수·컬러·양면별)과 수신자 엑셀 양식은 e-그린우편 화면 또는 우편고객센터 1588-1300 에서 확인.
처음엔 1차 300곳만 보내서 반응(문자·전화 수)을 보고 2차를 정하세요.

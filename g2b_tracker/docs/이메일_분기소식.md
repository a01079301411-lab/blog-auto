# 분기 소식 메일 (연 4회 자동)

첫 메일을 받은 모든 주소에 **3월·6월·9월·11월 첫째 주(1~10일, 평일)** 에 한 번씩 자동 발송합니다.
시기는 대구·경북 기관 이사 계약이 몰리는 달(12월 29%, 1월 12%, 7월 11%)의 4~6주 전에 맞췄습니다.

규칙
- 같은 주소에는 **최소 45일** 간격 (첫 메일 직후 바로 소식이 가지 않게)
- 같은 시기(예: 2026년 11월)에는 한 번만
- 수신거부한 주소는 영구 제외
- 회신이 없다고 전화·문자 같은 후속 조치는 하지 않음
- 첨부: 제안서 PDF 1개만 (서류 일체는 첫 메일에 이미 보냄)

제목의 `(광고)`: 정보통신망법상 영리 목적 광고성 메일은 제목 앞 `(광고)` 표시와 수신거부 방법을 넣어야 합니다 [업데이트 필요: 최신 법령 확인].
통화 때 "분기마다 소식 보내 드려도 될까요?"라고 동의를 받았더라도 표시는 그대로 두는 것이 안전합니다.

각 시기마다 제목과 본문 코드블록을 하나씩 둡니다. 문구를 고쳐도 됩니다.

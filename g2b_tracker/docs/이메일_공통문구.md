## 본문

```
○○ 담당자님, 안녕하십니까.
대구토탈홈서비스 로젠이사 영업 담당 서성민입니다.

공간재구조화·리모델링 같은 공사가 있을 때,
공사 전 집기 반출부터 준공 후 제자리 배치까지 한 업체가 맡아 드리는 일을 하고 있습니다.
다음 이사·집기 이전 견적을 받으실 때 저희도 견적 업체로 넣어 주시면 감사하겠습니다.

■ 담당자님이 하실 일은 세 가지뿐입니다
  실사 일정, 배치도 1장, 준공일만 알려 주시면
  포장 → 반출 → 보관 → 재반입 → 원위치 배치를 저희가 모두 합니다.

■ 공사가 늦어져도 짐 걱정이 없습니다
  100평 직영 실내창고(보안·24시간 제습·정기 방역)에 보관했다가
  준공 날짜에 맞춰 다시 들여옵니다. 보관 연장은 일 단위입니다.

■ 끝나고 "제 책상 어디 갔어요?"가 없습니다
  교실·부서·책상마다 색상·번호 라벨을 붙이고,
  반출·반입 때 인수인계표로 수량을 함께 확인합니다.

■ 해 온 일
  법원 문서고 약 3만 권 이전(2일), 공공기관 약 200평 사무실 30개 공간 재편(2일),
  대구·경북 11년, 정직원 팀, 주말·야간·방학 작업 가능.

■ 서류는 한 번에
  여성기업·장애인기업·소기업 확인서와 사업자·허가 서류를 첨부했습니다.
  여성기업·장애인기업 공공구매 실적 대상 업체입니다.

자세한 내용은 첨부한 제안서(4쪽)에 정리했습니다.
현장 실사는 무료이고 10~15분이면 됩니다.
공사 시기만 회신으로 알려 주셔도 일정에 맞춰 먼저 연락드리겠습니다.
```

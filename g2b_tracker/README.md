# 나라장터 추적 프로그램 (대구·경북 관공서 이사·이전·보관)

매일 아침 나라장터에서 대구·경북 공고를 전부 받아 와서, **우리 일감(이사·집기 이전·문서고·보관, 그리고 그 앞 단계인 리모델링·이전 구축)만 골라** 점수를 매기고 엑셀·브리핑·텔레그램으로 보내 줍니다.

```
발주계획(가장 빠름) → 사전규격 → 입찰공고 → 낙찰(원도급사)
   이전 시기 문의        범위 문의      견적·입찰       협력업체 영업
```

## 처음 설치 (15분)

### 1단계. 프로그램 받기
1. https://github.com/a01079301411-lab/blog-auto/archive/refs/heads/claude/magical-darwin-l927px.zip 받기
2. 압축 풀고 안의 `g2b_tracker` 폴더를 원하는 곳(예: `문서\나라장터추적`)에 복사

### 2단계. 공공데이터포털 인증키 (무료)
1. https://www.data.go.kr 회원가입·로그인
2. 검색창에 아래 5개를 하나씩 검색 → 각각 **[활용신청]** → 목적 "업무 활용(입찰 정보 확인)" → 신청 (보통 바로 자동승인)

   | 검색어 | 이 프로그램에서 쓰는 곳 |
   |---|---|
   | 조달청_나라장터 입찰공고정보서비스 | 입찰·견적 공고, 3번 기관찾기 |
   | 조달청_나라장터 사전규격정보서비스 | 공고 1~3주 전 신호 |
   | 조달청_나라장터 발주계획현황서비스 | 올해·내년 발주 예정 |
   | 조달청_나라장터 낙찰정보서비스 | 낙찰 원도급사(이름·전화) |
   | 조달청_나라장터 계약정보서비스 | **이사·이전 계약 체결 내역(수의계약 포함)과 그 계약을 처리한 기관 담당자** |

3. 마이페이지 → 개발계정 → 아무 서비스 → **일반 인증키(Decoding)** 복사

### 3단계. 실행
1. `0_처음설치.bat` → 인증키 붙여넣기 (텔레그램은 블로그 프로그램 설정을 자동으로 찾아 씀)
2. `1_연결점검.bat` → 전부 O 인지 확인 (신청 직후 1~2시간은 X 가 뜰 수 있음)
3. `2_지금추적.bat` → 첫 실행은 최근 30일치를 훑음 (몇 분)
4. `3_이사발주기관찾기.bat` → 3년치 (10~20분, 하루 호출 한도에 걸리면 다음 날 다시)
5. `4_자동실행등록.bat` → 매일 자동

## 점수 기준 (코어 프로필 기회점수)

| 항목 | 점수 |
|---|---:|
| 공고명에 이사·이전·집기·문서고·보관 직접 | +30 |
| 그게 용역·물품 공고 (우리가 바로 견적 내는 일) | +20 |
| 이전 구축·신청사·개청·개소·임시청사 | +25 |
| 리모델링·환경개선·공간재구조화·사무환경 (선행공사) | +20 |
| 기존 운영시설 (리모델링·개선) | +15 |
| 사무실·문서고·병원·학교 등 | +15 |
| 여성기업·장애인기업·소액수의·견적 공고 | +15 |
| 관심사업 (`data\watchlist.txt`) | +20 |
| 대구 근교 / 담당자 전화 있음 / 원도급사 확인 / 보관 가능성 | 각 +10 |
| 신축(기존 물품 없음) / 문화재·의료장비 등 특수운송 | −15 / −20 |
| 전기·소방·토목 등 하위 공사 | −10 |

- 마감 지난 공고는 '마감'(회색)으로 따로 모으고 알림에서 뺌. 낙찰되면 원도급사로 다시 뜸
- 같은 기관의 같은 사업(공종만 다른 공고)은 1건으로 묶음
- 폐기물·토사 운반 등은 무조건 제외

**60점 이상 = 즉시 연락 (빨강), 40~59 = 추적 (노랑), 40 미만 = 버림.**

## 알아 둘 것
- 학교 소액 계약 상당수는 나라장터가 아니라 **학교장터(S2B)** 에 올라옵니다. 이 프로그램은 S2B를 보지 않습니다. S2B 업체 등록은 따로 하세요.
- 기관이 나라장터를 거치지 않고 **견적 2~3곳 받아서 바로 하는 소액 수의계약**은 공고가 없습니다. 그 시장은 영업DB 기관에 직접 연락해서 '견적 받는 업체 명단'에 들어가는 게 유일한 방법입니다 → `docs\영업플레이북.md`
- 담당자 이름·전화는 공고에 공개된 업무 연락처만 씁니다. 대량 문자·메일 발송은 하지 않습니다.

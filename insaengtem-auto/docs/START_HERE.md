## 4단계 · Meta 토큰 발급 (40~60분) [업데이트 필요: 메타 화면 문구는 자주 바뀜]

**인스타그램**
1. 인스타 앱 → 설정 → 계정 유형 → **프로페셔널(크리에이터 또는 비즈니스)** 전환
2. 페이스북 페이지 1개 만들고 인스타 계정 연결 (명리리포트와 다른 페이지)
3. developers.facebook.com → 내 앱 → 앱 만들기 → 사용 사례 **"Instagram에서 메시지 및 콘텐츠 관리"(Facebook 로그인 방식)**
4. 그래프 API 탐색기에서 권한 체크: `instagram_basic`, `instagram_content_publish`, `instagram_manage_insights`, `instagram_manage_comments`, `pages_show_list`, `pages_read_engagement` → 토큰 생성
5. 장기 토큰(60일)으로 교환 → [설정] `IG_ACCESS_TOKEN`
6. 탐색기에서 `me/accounts?fields=instagram_business_account` 실행 → 나온 id → [설정] `IG_USER_ID`

**스레드**
1. 같은 앱(또는 새 앱)에 사용 사례 **"Threads API 액세스"** 추가
2. 권한: `threads_basic`, `threads_content_publish`, `threads_manage_insights`, `threads_manage_replies`, `threads_read_replies`, `threads_keyword_search`
3. 역할 → Threads 테스터에 `@insaengtem_lap` 추가 → 스레드 앱 설정 → 계정 → 웹사이트 권한 → 초대 수락
4. 토큰 생성 → 장기 토큰 교환 → [설정] `THREADS_ACCESS_TOKEN`, 사용자 id → `THREADS_USER_ID`
5. 이후 토큰은 매주 일요일 자동 갱신

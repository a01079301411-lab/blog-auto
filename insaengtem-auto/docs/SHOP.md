# 한 곳에서 다 팔기 — 링크샵 운영

## 결론
| 방법 | 장점 | 단점 | 추천 |
|---|---|---|---|
| **A. 내 링크샵 (프로그램이 자동 생성)** | 제품 수 무제한, 품절 자동 제외, 제품 번호(영상 캡션 "링크샵 23번"), 1개당 가격·무료배송 뱃지 자동, 매주 자동 갱신, 무료 | R2 1회 설정 필요, 클릭 통계는 COSY 쪽에서 확인 | ✅ 메인 |
| B. 인포크링크 | 5분 만에 시작, 클릭 통계 내장, 익숙한 화면 | 제품 하나하나 손으로 입력·삭제, 품절 수동 관리, 자동 연동 API 확인 안 됨 [확인 필요] | 보조 / 당장 오늘 |
| C. 둘 다 | 인스타 프로필 1번 = 내 링크샵, 2~5번 = 이번 주 영상 제품 직링크 | — | ✅ 최종 구조 |

## 프로필 링크 5칸 배치 (C안)
1. 🛒 전체 제품 링크샵 (번호로 찾기) ← 내 링크샵 주소
2~5. 이번 주 영상 속 제품 직링크 (관리 화면 [홈] 표 그대로)

## 사용법 (관리 화면 [링크샵·제품] 탭)
1. **제품 대량 등록**: COSY 앱에서 오픈딜 링크를 계속 복사해 메모장에 모아뒀다가 통째로 붙여넣기 → [등록]
   - 같은 제품은 갱신, `sl=` 없는 링크는 자동 제외, 새 제품엔 고정 번호 부여
2. **새 제품 정보 수집**: 상품명·가격·옵션·배송비·사진·품절 자동 수집, 카테고리 자동 분류(표에서 수정 가능)
3. **링크샵 만들기 → 미리보기 → 인터넷에 올리기(R2)**: 주소가 자동으로 `SHOP_PUBLIC_URL`에 저장되고 프로필 링크 1번 칸에 들어감
4. 매주 일요일 자동: 품절 재확인 → 링크샵 재생성·업로드 → 이번 주 영상 제품 7개 자동 선정(고정 체크 우선 → 최근 2주 안 나간 제품 → 성과 좋은 제품)
5. 인포크링크도 쓰려면 [인포크링크용 목록(엑셀)] → 번호·제목·가격 문구·URL·사진 파일 경로가 정리된 표를 보고 인포크 편집 화면에 옮겨 적기

## 주의
- 링크샵 상단에 **[광고] 제휴 링크 고지**가 자동으로 들어감 (공정위 추천·보증 지침)
- r2.dev 주소는 Cloudflare가 '테스트용'으로 안내 → 트래픽이 늘면 내 도메인(예: shop.도메인) 연결 권장
- COSY 오픈딜 약관에서 제휴 링크를 외부 페이지(링크샵·인포크)에 게시하는 것이 허용되는지 한 번 확인 [확인 필요]

# 2026-11 트렌드 조사 → 프로그램 반영

> 조사일 2026-11-03. 표기: [사용자 실측] [외부 확인-1차(공식)] [외부 확인-2차(블로그·보도)] [추정]
> ⚠️ 이 클라우드 세션은 instagram.com·threads.com·developers.facebook.com 직접 접속이 막혀 있어, **개별 게시물 조회수 실측은 못 했음**. 대신 프로그램에 공식 API 기반 수집기(`trends`)를 넣어 사용자 PC에서 매주 자동으로 '최근 30일 상위 게시물'을 모으도록 함.

## 2. 레퍼런스 → 빌린 패턴 → 우리 버전

| 레퍼런스(유형) | 빌린 패턴 | 우리 버전(새로 씀) |
|---|---|---|
| 계정 1위 스레드 "택배 오면 '이거 왜 샀더라?'" 295회 [사용자 실측] | 누구나 겪는 장보기 고백 + 질문 | "장바구니에 넣어두고 일주일째 결제 못 한 거 있는 사람?" |
| 릴스 랭킹 = 시청시간 [2차] | 답이 끝에 나오는 3초 퀴즈 | "60구 사면 배송비는? 1) 무료 2) 있음" (v5) |
| 랭킹 = sends per reach [2차] | 보낼 대상을 지정한 CTA | "📩 이번 주 장 보는 사람한테 보내두기" |
| 체크리스트형 저장 [2차] | 01·02·03 + 저장 CTA | "결론부터: 1팩 7,700원 / 50년 이남장 / 국내산 소고기" (v6) |
| 비교형 신뢰도 [2차] | 같은 상품 구성 비교(타사 비교 금지) | "20구 말고 60구 — 138원↓" (v4) |

## 3. 매주 자동 갱신 방법
1. `.env`에 IG/Threads 토큰 설정 (Threads keyword_search 권한 필요)
2. `python -m insaengtem trends` → `data/trends/report_YYYY-MM-DD.md` (상위 레퍼런스 링크·날짜·점수·패턴)
3. 사람이 직접 본 터진 게시물은 `python -m insaengtem trends add --url <링크> --platform instagram --views 120000 --text "첫 줄"`
4. 결과는 `patterns.json` 가중치로 들어가 다음 `generate`(Claude 프롬프트)에 반영. 레퍼런스 문장과 60% 이상 비슷하면 검수에서 차단(COPY).

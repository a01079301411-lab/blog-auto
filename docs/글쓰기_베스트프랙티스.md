# 블로그 글쓰기 베스트 프랙티스 (원소 단위 정리)

프로그램 글쓰기 규칙(`prompts/moving_post.md`)과 품질 검사(`src/checker.py`)의 근거 문서다.
네이버는 검색 알고리즘의 세부 기준을 공개하지 않는다. 그래서 출처마다 신뢰도를 표시했다.

- **[공식]** 네이버나 네이버 관계자가 직접 밝힌 내용
- **[다수]** 여러 실무 자료가 공통으로 말하는 내용 (공식 아님)
- **[사장님]** 사장님이 직접 쓴 샘플 글에서 뽑은 기술
- **[초사고]** 자청 초사고 글쓰기 목차와 리뷰에서 확인한 원리

## 1. 네이버 검색이 글을 평가하는 축

| 원소 | 내용 | 신뢰도 | 프로그램 반영 |
|---|---|---|---|
| 블로그 신뢰도 (C-Rank) | 한 주제를 꾸준히 쓰는 블로그를 우대 | [다수] | 이사 주제만 발행, 개인 카테고리는 비공개 |
| 문서 품질 (D.I.A.) | 검색 의도에 맞는 문서, 체류 시간 | [다수] | 한 글 한 질문, 도입부 3문장 안 결론 |
| 경험 콘텐츠 | 실제 경험과 인사이트가 담긴 글을 AI 브리핑에 인용 | [공식] | 소제목마다 현장 경험 문장 1개 |
| 어뷰징 제재 | 광고, 스팸, 도배, 매크로는 제재. AI 사용 여부 자체로는 제재 안 함 | [공식] | 하루 글 수 제한, 매 글 다른 틀 |
| 유사 문서 | 비슷한 글 반복, 하지 않은 경험 꾸미기는 검색 제한 위험 | [다수] | 상투 문장 금지, 같은 문장 반복 금지, 지어낸 사연 금지 |
| 키워드 도배 | 같은 키워드 과다 반복은 불리 | [다수] | 메인 6번 + 연관 키워드 2~3개로 분산 |
| 스마트블록 | 검색 의도를 잘게 나눠 블록으로 노출 | [다수] | topics.md의 "단 하나의 질문" |

## 2. 스니펫, AI 브리핑에 뽑히는 원소

| 원소 | 규칙 | 신뢰도 | 검사 |
|---|---|---|---|
| 첫 문단 즉답 | 제목 질문의 결론을 도입부 3문장 안에 | [다수] | 키워드 첫 3문장 안 (기존) |
| 질문형 소제목 | 실제 검색어 말투의 질문 | [다수] | 질문형 3개 이상 (기존) |
| 떼어 가는 답 | 소제목 바로 아래 첫 문장이 그 자체로 완결된 답, 주어는 명사 | [다수] | "네, 아래에서, 이건"으로 시작하면 탈락 |
| 섹션 독립성 | 각 소제목만 떼어 읽어도 이해됨 | [다수] | 지시문 |
| 목록 | 첫째, 둘째, 셋째 목록 한 덩어리 | [다수] | 지시문 |
| 기준 붙은 숫자 | 5톤 기준 하루 7,000원처럼 | [다수] | 회사 팩트 2개 이상 (기존) |
| 원본 사진 | 직접 찍은 사진, 5장 안팎 | [다수] | 사진 4장 이상 사용 (기존) |

## 3. 제목 원소

| 원소 | 규칙 | 신뢰도 |
|---|---|---|
| 키워드 위치 | 메인 키워드를 제목 앞 10글자 안에 | [다수] (검사로 강제) |
| 길이 | 25자에서 38자 | [다수] |
| 기호 | 쉼표, 마침표 없이 | [다수] (프로그램이 자동으로 뺌) |
| 추상어 금지 | 꼼꼼한, 합리적인 대신 장면과 숫자 | [초사고] 추상어의 저주 |
| 제목 공식 7가지 | 상식 파괴, 금지 경고, 자아 자극, 권위 부여, 호기심, 구체 장면, 숫자 목록 | [초사고] 6가지 공식 + 숫자 목록 |
| 반복 금지 | 11년은 권위 부여형만, N가지는 숫자 목록형만 | 지난 글 분석 결과 (검사로 강제) |

## 4. 도입부 원소

| 원소 | 규칙 | 출처 |
|---|---|---|
| 두 줄 펀치 | 독자의 지금 행동을 짚고 바로 뒤집기 | [사장님] |
| 결론 | 3문장 안에 메인 키워드가 주어인 결론 | [다수] |
| 권위 | 4문장 안에 회사 팩트 숫자 하나, 매번 다른 팩트 | [초사고] 권위 부여 |
| 광고 티 늦게 | 도입부에 회사 이름, 자랑 금지 | [초사고] 방어기제 피하기 |
| 상투 문장 금지 | 끝까지 보시면, 아시게 됩니다, 들어보셨죠 | 지난 글 분석 결과 (검사로 강제) |

## 5. 본문 원소

| 원소 | 규칙 | 출처 |
|---|---|---|
| 본질 강화 | 핵심 메시지 한 문장에 모든 소제목을 맞춤 | [초사고] |
| 반박 제거 | 속마음 소제목, 인정 후 반전 | [사장님] [초사고] |
| 가치 입증 | 형용사 대신 숫자와 사실 | [초사고] |
| 대비 펀치라인 | 문단 끝을 짧은 대비 한 줄로 | [사장님] |
| 현장 디테일 | 현장 사람만 아는 반복 장면 | [사장님] [공식] 경험 콘텐츠 |
| 사진과 글 연결 | 사진 앞뒤 문장에서 사진 내용 언급 | [다수] |
| 내부링크 | 이어 읽을 글 1~3개 (체류 시간) | [다수] |
| 댓글 유도 | A, B, C 고르기 질문 | [다수] |
| FAQ | 본문 되풀이 금지, 새 정보로 | 지난 글 분석 결과 (검사로 강제) |

## 6. 문장 원소 (초사고 SEDA)

| 원소 | 규칙 |
|---|---|
| 짧게 | 한 문장 40자 안팎 |
| 쉽게 | 중학생도 바로 이해, 업계 용어는 풀어 쓰기 |
| 나누기 | 같은 내용 2~4문장 한 문단, 내용 바뀔 때만 빈 줄 |
| 다시 읽기 | 다 쓴 뒤 독자 입장에서 점검 목록대로 다시 읽기 |

## 7. 아직 확인 못 한 것 (데이터로 확인할 것)

- 사진 개수, 글자 수의 최적값은 자료마다 다르다. 블로그 통계(유입 검색어, 체류 시간)로 직접 비교해야 한다.
- 네이버가 스니펫과 AI 브리핑 인용 기준을 공개하지 않아서, 위 2번은 실무 경험 기반이다.
- 파워블로거 실제 글은 사장님이 레퍼런스로 주시면 이 표에 원소를 추가한다.

# 블로그 성과 진단과 개선 (2026년 10월 27일)

사장님 말씀: "지금까지 올린 글에 아무 성과가 없다."
지금 글을 원소 단위로 쪼개서, 온라인에서 공개된 자료와 하나씩 비교했다.

## 0. 먼저 알아둘 한계

- 네이버는 검색 순위, 홈판, AI 브리핑의 계산 방식을 공개하지 않는다. 아래 기준은 대부분 마케팅 업체와 블로거의 경험 자료이고, **[공식]**으로 표시한 것만 네이버나 언론 보도로 확인된 내용이다.
- 이 작업 환경에서는 네이버 블로그와 검색 페이지가 열리지 않는다. 상위 블로그 글을 직접 열어 세지는 못했고, 공개 분석 자료로 대신했다.
- 자동 발행은 10월 11일에 시작했다. 2주 남짓은 성과를 판단하기에 짧다. 그래도 아래 문제는 기다린다고 풀리지 않으니 지금 고친다.

## 1. 원소별 진단

| 원소 | 지금 우리 글 | 참고 자료가 말하는 것 | 판정 | 조치 |
|---|---|---|---|---|
| 키워드 선택 | "대구 포장이사 견적"처럼 큰 키워드 위주 | 신규나 약한 블로그는 큰 키워드로 상위에 오르기 어렵다. 월 검색량 500~10,000 사이의 세부 키워드, 상위 10개에 파워블로그나 업체가 적은 키워드를 고른다 (블로그스왓, 키워드마스터, 탬블마케팅) | **가장 큰 문제** | 구별 세부 키워드 7개 추가. 사장님이 키워드도구로 검색량 확인 |
| 경험 | AI가 회사 정보로 쓴 일반 설명 | **[공식]** 네이버는 실제 경험과 인사이트가 담긴 글을 AI 브리핑에 인용한다. 독자와 상황을 구체적으로 정하고 가격, 시간 같은 실용 정보를 주라 (머니투데이 2026.6, xeolab) | **큰 문제** | 현장 폴더에 `메모.txt`를 두면 현장 후기형으로 씀 |
| 사진 | 공용 폴더 사진을 여러 글에 돌려 씀 | 같은 사진, 유사 이미지를 반복하면 누락 원인이 될 수 있다. 직접 찍은 원본을 쓰라 (중복 이미지 경험담 여러 건, 공식 아님) | **위험** | 한 번 발행한 사진은 다시 안 씀 |
| 같은 글 두 번 | 10월 12, 13일에 같은 글이 두 번 올라감 | 유사 문서 반복은 누락 위험 (저품질 진단 자료 여러 건) | 지난 문제 | 이미 고침. 남은 중복 글은 삭제 |
| 발행 방식 | 브라우저 자동화로 하루 1개 | 공식 API가 없어 자동화는 정책 위험이 있다. 하루 1~3개가 안전하다는 주장이 있으나 근거는 없음 (자동화 도구 업체) | 주의 | 하루 1개 유지 |
| 제목 | 30~45자, 후킹 위주 | 검색용은 키워드를 앞에, 25자 안팎 (여러 가이드). 홈판용은 호기심 | 조정 | 25~35자, 키워드 앞 |
| 첫 문단 | 두 줄 펀치 + 결론 | 결론 먼저 (AI 브리핑 자료 공통) | 맞음 | 유지 |
| 소제목 | 질문형 | 실제 검색어 말투의 질문형 (아이보스) | 맞음 | 유지 |
| 키워드 반복 | 5번 | 3~5번 (가이드 공통) | 맞음 | 유지 |
| 글자 수 | 1,700~2,000자 | 600~2,000자로 자료마다 다름 | 맞음 | 유지 |
| 사진 수 | 최대 6장 | 원본 5장 이상 (가이드) | 맞음 | 유지 |
| 플레이스 | 블로그만 운영 | 지역 업종 검색은 플레이스와 리뷰가 크게 작용하고, 상호, 전화, 주소가 블로그와 같아야 한다 (플레이스 가이드) | 프로그램 밖 | 사장님 확인 필요 |
| 홈판 | 회사 블로그에서 노리는 중 | 홈판은 관심사 기반 개인화 추천이라 반응과 체류가 중요 (공식 기준 없음) | 회사 블로그엔 우선순위 낮음 | 검색 노출에 집중 |

## 2. 이번에 바꾼 것

1. **사진 중복 금지**: 발행한 글에 들어간 사진 이름을 기록하고, 공용 사진은 한 번 쓴 것을 다시 고르지 않는다.
2. **현장 메모**: 현장 사진 폴더에 `메모.txt`를 넣으면 그 내용(평수, 층, 인원, 시간, 특이사항)을 뼈대로 현장 후기 글을 쓴다.
3. **세부 키워드**: 수성구, 달서구, 북구, 동구, 남구, 중구, 달성군 포장이사를 주제에 추가했다.
4. **독자 구체화**: 글마다 독자 한 명과 상황을 정하고 가격, 시간, 인원, 순서 같은 실용 정보를 주도록 지시했다.
5. **제목 길이**: 25~35자.

## 3. 사장님이 해야 확인되는 것

1. **누락 확인**: 최근 글 3개의 제목을 통째로 복사해서 네이버에서 검색한다. 내 글이 안 나오면 글 내용 문제가 아니라 누락 문제다.
2. **키워드 검색량**: 네이버 검색광고의 키워드도구에서 주제표의 메인 키워드 검색량을 확인한다. 월 검색량이 너무 적거나 너무 많은 키워드는 바꾼다.
3. **블로그 통계**: 관리 → 내 블로그 통계 → 유입분석 → 검색어 화면을 2주마다 보낸다.
4. **플레이스**: 네이버 플레이스(지도) 등록 여부와 상호, 전화, 주소가 블로그와 같은지 확인한다.

## 4. 성과를 재는 방법

| 기간 | 볼 것 |
|---|---|
| 1주 | 새 글이 제목 검색으로 나오는지 (누락 여부) |
| 2~4주 | 구별 세부 키워드에서 몇 위에 나오는지, 유입 검색어에 세부 키워드가 생기는지 |
| 1~2달 | 전화 문의 중 "블로그 보고 연락했다"는 건수 |

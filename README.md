# blog-auto

## shortform: 롱폼 영상 → 숏폼 자동 편집기

긴 영상을 넣으면 다음 작업을 자동으로 해요.

1. **자동 자막**: Whisper로 음성을 인식하고 단어 단위 타이밍으로 자막을 만들어요.
2. **하이라이트 선정**: 대본을 Claude에게 보내 숏폼으로 쓰기 좋은 구간을 골라요. 제목, 강조 단어, 인물 소개, 하단 문구, 업로드 설명도 같이 만들어요.
3. **무음 구간 제거**: 말 없는 부분을 잘라 템포를 빠르게 만들어요.
4. **세로 숏폼 렌더링**: 레퍼런스 템플릿 디자인으로 1080x1920 영상을 만들어요.

직접 찍은 여러 촬영본과 기획안으로 **롱폼(유튜브 가로 영상)** 도 만들어요. 아래 [롱폼 만들기](#롱폼-만들기)를 보세요.

## Windows 설치 (처음 한 번만)

### 1. 프로그램 내려받기

1. https://github.com/a01079301411-lab/blog-auto 에 접속해요.
2. 왼쪽 위 브랜치 선택에서 `claude/ecstatic-lamport-5i53ft`를 고르고, 초록색 **Code → Download ZIP**을 눌러요.
3. 압축을 풀어서 원하는 곳(예: `C:\shortform`)에 둬요.

### 2. install.bat 실행

압축 푼 폴더의 **`install.bat`을 더블클릭**해요. 이 파일이 다음을 자동으로 해요.

- Python과 FFmpeg이 없으면 설치해요 (Windows 기본 `winget` 사용).
- 필요한 파이썬 패키지를 설치해요.
- Claude API 키를 물어보고 저장해요.

> Python이나 FFmpeg을 새로 설치했다면 창을 닫고 `install.bat`을 **한 번 더** 실행해야 해요.
>
> "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누르세요.

**Claude API 키**는 https://console.anthropic.com 에서 가입한 뒤 **API Keys → Create Key**로 만들어요. 결제 수단 등록이 필요해요. 1시간 영상 한 편을 분석하는 데 몇백 원 정도 들어요.

### 3. 글꼴 (선택)

기본 글꼴은 Windows에 있는 **맑은 고딕(굵게)**이에요. 레퍼런스처럼 더 굵고 임팩트 있는 글꼴을 쓰려면 무료 글꼴을 설치하세요.

- G마켓 산스: https://corp.gmarket.com/fonts
- Pretendard: https://github.com/orioncactus/pretendard/releases

설치한 뒤 스타일 파일에 `"font": "Gmarket Sans TTF Bold"`처럼 글꼴 이름을 적으면 돼요.

### 수동 설치 (install.bat이 안 될 때)

1. https://www.python.org/downloads/ 에서 Python을 설치해요. 설치 첫 화면에서 **"Add python.exe to PATH" 체크**를 꼭 해야 해요.
2. 명령 프롬프트(cmd)에서 아래를 실행해요.
   ```bat
   winget install Gyan.FFmpeg
   cd C:\shortform
   python -m pip install -r requirements.txt
   setx ANTHROPIC_API_KEY "sk-ant-..."
   ```
3. cmd 창을 닫았다가 다시 열어요.

## 프로그램 창으로 쓰기 (추천)

바탕화면의 **"숏폼 자동 편집기"** 아이콘을 더블클릭하면 프로그램 창이 열려요.

- 아이콘은 `run.bat`을 한 번 실행하거나 `install.bat`을 실행하면 자동으로 생겨요.
- 아이콘이 없으면 `app.bat`을 더블클릭해도 돼요.

1. **[영상 추가...]**로 영상을 골라요. 바탕화면 아이콘 위로 영상을 끌어다 놓아도 돼요. 여러 개를 넣으면 차례로 만들어요.
2. 디자인, 개수, 영상 설명, 자동 편집 기능을 화면에서 정해요. 정한 값은 `settings.ini`에 저장돼서 다음에도 그대로 나와요.
3. **[숏폼 만들기]**를 누르면 진행 상황이 창 아래에 보여요. **[중지]**로 멈출 수 있고, 다시 누르면 이어서 해요.
4. 기본은 **고르는 단계 없이 바로 끝까지 만들어요.** [고급 설정]에서 "만들기 전에 목록 보고 고르기"를 켜면 **체크박스 목록**이 떠요 (3분 동안 아무것도 안 누르면 그대로 진행). 만들 것만 체크하고 제목·하단 문구·구간을 고친 뒤 **[선택한 숏폼 만들기]**를 누르면 돼요.
5. 다 되면 결과 폴더가 열려요.

프로그램을 켤 때마다 최신 버전을 확인하고, 바뀐 게 있으면 자동으로 업데이트한 뒤 다시 열려요.

## 사용법

### 가장 쉬운 방법: 끌어다 놓기

**영상 파일을 `run.bat` 위로 끌어다 놓으면** 끝이에요. 다 되면 결과 폴더(`영상이름_shorts`)가 자동으로 열려요.

설정은 **`settings.ini`를 메모장으로 열어서** 바꾸면 돼요.

```ini
style = green
count = 7
context = 꼴통사장 권기준 대표의 사업 강의. 창업, 매출, 사장 마인드, 크리에이터로 돈 버는 법
speaker = 권기준 / 꼴통사장 대표
focus = 0.5
model = small
```

### 업데이트

**`update.bat`을 더블클릭**하면 최신 버전을 받아서 덮어써요. `settings.ini`는 그대로 둬요.

또 `run.bat`을 실행할 때마다 GitHub에서 최신 버전을 확인하고 바뀐 파일만 자동으로 받아와요. 따로 다시 내려받을 필요가 없어요.

- `settings.ini`는 덮어쓰지 않아요.
- 인터넷이 안 되면 업데이트를 건너뛰고 지금 버전으로 실행해요.
- 영상 없이 `run.bat`을 더블클릭하면 업데이트만 해요.

### 결과물

숏폼마다 파일이 세 개씩 나와요.

- `01_제목.mp4`: 완성된 숏폼
- `01_제목.txt`: 제목, 알약 문구, 인물, 하단 문구, **업로드 설명과 해시태그**, 원본 구간, 선정 이유
- `01_제목.ass`: 자막 파일. 메모장으로 고칠 수 있어요.

### 명령어로 쓰기

```bat
:: 하이라이트 숏폼 7개
python -m shortform shorts 영상.mp4 -n 7 --style green --context "영상 설명"

:: 구간과 제목을 직접 지정 (AI 안 씀). /로 줄 바꿈, {}로 강조
python -m shortform shorts 영상.mp4 --ranges "12:30-13:15=사장님 속터지는/{진상 직원}의 한마디"

:: 영상 전체의 무음만 잘라내기
python -m shortform silence 영상.mp4

:: 자막(SRT)만 만들기
python -m shortform subtitle 영상.mp4
```

## 코시 인스타 계정 가이드대로 만들기

코시 육성프로그램의 **"계정별 썸네일 영상 제작 가이드"**와 **"인스타 계정 운영 가이드"**가 그대로 들어 있어요.

### 쓰는 방법

1. 프로그램 창 **"② 코시 계정 디자인"**에서 만들 계정을 체크하고 **계정마다 개수**를 정해요 (영상 종류가 강의일 때만 고를 수 있어요). 계정을 고르면 ③ 설정의 숏폼 개수·디자인은 쓰지 않아요. 퀘스트는 채널마다 3개예요.
2. **[숏폼 만들기]**를 누르면 계정마다 이렇게 만들어요.
   - 그 계정의 **컨셉과 타깃에 맞는 구간**을 Claude가 골라요. 계정끼리 같은 구간은 쓰지 않아요.
   - 제목, 부제목, 설명자막 `[ ]`, 하단자막 `< >`을 그 계정 말투로 써요.
   - 그 계정 가이드의 **글꼴, 색, 배치** 그대로 영상을 만들어요.
3. 결과는 **계정(채널)별 폴더**에 저장돼요. 구글드라이브에 폴더째 올리면 돼요.

```
영상이름_shorts/
  01_대표들의 말 못할 비밀/
    01_진상_직원의_한마디.mp4          ← 숏폼 영상
    01_진상_직원의_한마디_썸네일.png   ← 썸네일 (1080x1920 PNG)
    01_진상_직원의_한마디.txt          ← 제목, 업로드 설명, 해시태그
  04_꼴통 강사 권기준/
    ...
```

### 가이드의 어떤 배치로 만드나요?

| 원본 영상 | 가이드 | 화면 |
|---|---|---|
| 가로로 찍은 롱폼 | **N-4 롱폼 잘라 쓴 숏폼** | 영상은 가운데 네모(y 432~1533)에만, 위에 제목, 아래 하단자막 |
| 세로로 찍은 영상 | **N-3 세로 촬영본** | 영상이 화면 전체, 제목과 자막은 영상 위에 |
| 썸네일 | **N-1 썸네일** | 계정별 예시 이미지와 같은 배치 (아래 어둡게, 알약 부제목, 모눈종이 상자 등) |

어느 배치로 만들지는 영상 방향을 보고 자동으로 정해요.

### 글꼴 준비 (중요)

가이드 글꼴(강한육군, 둘기마요_고딕, 페이퍼로지, 박물관문화재단클래식 등)이 있어야 가이드와 똑같이 나와요. 둘 중 한 가지만 하면 돼요.

- 코시 가이드의 **[3.폰트] 폴더 글꼴을 모두 설치**하기
- 또는 글꼴 파일을 프로그램의 **`fonts` 폴더에 넣기** (설치 안 해도 돼요)

프로그램 창의 **[글꼴 확인]** 버튼을 누르면 계정별로 어떤 글꼴이 있고 없는지 보여줘요. 없는 글꼴은 맑은 고딕(굵게)으로 대신 만들어요.

### settings.ini로 정하기

```ini
accounts = 1,2,3,4    # 만들 계정 번호 (비우면 계정 없이 style 디자인으로)
per_account = 3       # 계정당 개수
```

## 하이라이트를 고르는 방법

두 단계로 골라서, 확실한 구간만 숏폼으로 만들어요.

1. **후보 찾기**: 대본 전체를 문장 단위로 보고, 필요한 개수의 3배쯤 후보를 뽑아요.
2. **엄격하게 다시 검증하기**: 후보마다 앞뒤 대본을 같이 보고, 처음 보는 시청자 입장에서 점수를 매겨요.
   - **훅**: 첫 3초가 스크롤을 멈추게 하는지 ("그래서", "아 그리고" 같은 도입은 감점)
   - **결론**: 확실한 한 방이나 교훈이 있는지
   - **이해**: 앞부분 영상 없이도 이해되는지
   - **컨셉**: 계정 컨셉과 맞는지

   하나라도 6점 미만이면 버려요. 통과한 구간은 훅이 시작하는 문장부터 결론 문장까지로 경계를 다시 다듬어요.

숏폼 고르기 화면의 "선정 이유"에 판단 이유와 점수가 나와요. 확실한 구간이 모자라면 개수를 억지로 채우지 않고 통과한 것만 만들어요.

## 자동으로 해 주는 것들

`settings.ini`에서 각각 켜고 끌 수 있어요(`yes`/`no`).

| 기능 | 설정 | 설명 |
|---|---|---|
| 얼굴 따라가기 | `focus = auto` | 사람이 찍듯이 따라가요: 장면이 바뀌면 바로 넘어가고, 한 장면 안에서는 고정했다가 사람이 화면 밖으로 벗어날 때만 부드럽게 옮겨요. 두 사람이 다 들어가면 같이 잡고, 안 들어가면 주인공을 계속 잡아요. 숫자를 넣으면 고정 위치 |
| 자막 다듬기 | `fix_subtitles = yes` | Claude가 음성 인식 오타를 문맥으로 고치고, 자연스러운 곳에서 줄을 나눠요 |
| 만들기 전에 고르기 | `review = no` | 켜면(yes) 메모장으로 숏폼 목록이 열려요. `[O]`를 `[X]`로 바꾸면 빼고, 제목·문구·구간도 고칠 수 있어요. 저장하고 닫으면 시작해요 |
| 원본 자막 그대로 쓰기 | `burned_subs = auto` | 원본 영상에 자막이 박혀 있으면 새 자막을 넣지 않고, 원본 자막이 잘리지 않게 화면을 넓게 잡아요 |
| 배경음악 | `bgm_volume = 0.15` | `bgm` 폴더에 음악 파일을 넣으면 숏폼마다 돌아가며 깔아요. 말할 때는 음악이 자동으로 작아져요 |
| 썸네일 | `thumbnail = yes` | 얼굴이 가장 잘 나온 장면에 제목을 얹은 이미지(`.jpg`)를 만들어요 |
| 유튜브 업로드 | `upload = no` | 아래 설정을 마치면 자동으로 올려요 |

같은 영상을 다시 끌어다 놓으면, 지난번에 고른 하이라이트와 음성 인식 결과를 다시 써서 금방 끝나요. 하이라이트를 새로 고르게 하려면 결과 폴더의 `highlights.json`을 지우세요.

배경음악은 저작권 걱정 없는 곡을 쓰세요. 유튜브 스튜디오 → **오디오 보관함**에서 무료 음악을 받을 수 있어요.

### 유튜브 자동 업로드 설정 (선택)

> **먼저 알아둘 점**: 구글 정책상, 구글 심사를 받지 않은 개인 API 프로젝트로 올린 영상은 **비공개로 고정**돼요. 공개로 바꾸려면 구글에 [심사 신청](https://support.google.com/youtube/contact/yt_api_form)을 해야 해요. 그 전까지는 "비공개로 올려두고 휴대폰 유튜브 앱에서 확인하는 용도"로 쓰거나, 직접 올리는 게 나아요.
>
> 또 하루에 올릴 수 있는 개수가 **약 6개**로 제한돼요. 남은 건 다음 날 다시 실행하면 이어서 올려요.

1. https://console.cloud.google.com 에 접속해 **새 프로젝트**를 만들어요.
2. **API 및 서비스 → 라이브러리**에서 `YouTube Data API v3`를 찾아 **사용**을 눌러요.
3. **OAuth 동의 화면**에서 다음을 해요.
   - 사용자 유형은 **외부**로 골라요.
   - 앱 이름과 이메일을 적어요.
   - **테스트 사용자**에 내 구글 계정을 추가해요.
4. **사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**로 들어가요.
   - 유형은 **데스크톱 앱**으로 골라요.
   - 만든 뒤 **JSON 다운로드**를 눌러요.
5. 받은 파일 이름을 `client_secret.json`으로 바꿔서 프로그램 폴더(`run.bat`이 있는 곳)에 넣어요.
6. `settings.ini`에서 `upload = private`으로 바꿔요.
7. 처음 실행할 때 브라우저가 열리면, 유튜브 채널의 구글 계정으로 로그인해서 **허용**을 눌러요.
   - "확인되지 않은 앱" 화면이 나오면 **고급 → 이동**을 누르세요.

테스트 모드에서는 로그인이 7일마다 풀려요. 다시 브라우저가 열리면 한 번 더 허용해 주세요.

| 스타일 | 모양 |
|---|---|
| `green` (기본) | 검은 배경. 위에 제목(첫 줄 작게, 강조는 초록), 가운데 확대 영상, 영상 안 노란 `[인물 소개]`와 말자막, 맨 아래 초록 `<반응 문구>` |
| `magenta` | 위와 같고 강조가 분홍색, 하단 문구 없음 |
| `overlay` | 영상이 화면 전체. 위에 보라색 알약 문구와 굵은 테두리 제목 |
| `basic` | 16:9 영상 전체가 보이고, 위 제목과 아래 자막 |

### 내 스타일 만들기 (제작 가이드에 맞추기)

```bat
python -m shortform style green > 내스타일.json
```

`내스타일.json`을 메모장으로 열어 숫자와 색을 바꾸고 `--style 내스타일.json`으로 쓰면 돼요. 바꿀 항목만 남겨도 돼요.

```json
{
  "base": "green",
  "font": "Gmarket Sans TTF Bold",
  "title_highlight": "#FF3B30",
  "video_top": 480,
  "sub_size": 80
}
```

좌표는 1080x1920 화면 기준 픽셀이에요. 주요 항목은 이래요.

- `video_top`, `video_height`: 영상 상자의 위치와 높이
- `title_*`: 제목 크기, 색, 강조색, 위치
- `speaker_*`: 노란 인물 소개 줄
- `sub_*`: 말자막
- `bottom_*`: 하단 반응 문구
- `label_*`: 알약 문구

## 옵션

| 옵션 | 설명 |
|---|---|
| `--style` | 디자인 (위 표 참고) |
| `--context "..."` | 영상 설명. 하이라이트와 제목이 더 정확해져요 |
| `--speaker "..."` | 인물 소개 문구 고정 |
| `--focus auto` | `auto`는 얼굴 따라가기. 숫자를 넣으면 좌우 고정 위치(0은 왼쪽, 1은 오른쪽) |
| `-n 7` | 숏폼 개수 |
| `--min-len 20 --max-len 60` | 숏폼 길이 범위(초) |
| `--model small` | 음성 인식 모델. `medium`, `large-v3`가 더 정확하지만 느려요 |
| `--noise -35 --min-silence 0.5` | 무음 판단 기준. 배경음악이 있으면 `--noise -30` |
| `--padding 0.15` | 자른 부분 앞뒤에 남길 여유. 말이 뚝뚝 끊기면 늘리세요 |
| `--device cpu` | GPU 문제가 생길 때 CPU로 강제 |

## 긴 영상 (몇 시간짜리)

- **음성 인식**: 약 10분 단위로, 가능하면 무음 지점에서 잘라 인식하고 남은 예상 시간을 보여줘요.
- **이어하기**: 중간에 멈추거나 `Ctrl+C`로 끊어도, **같은 명령을 다시 실행하면 끝난 부분부터 이어서** 해요.
- **재사용**: 음성 인식 결과는 저장돼요. 개수나 스타일만 바꿔 다시 돌리면 금방 끝나요.
- **걸리는 시간**: CPU만 쓰면 음성 인식에 영상 길이의 1/3에서 2/3 정도 걸려요. NVIDIA GPU가 있으면 자동으로 쓰고, 안 되면 알아서 CPU로 바꿔요.

## 영상 종류 (숏폼 가이드)

숏폼 설정 맨 위 **영상 종류**를 고르면, AI가 그 영상에 맞는 장면과 제목 말투로 골라요.

가이드는 두 층이에요.
1. **공통 이론** (모든 종류에 들어가요): 장르와 상관없이 잘되는 숏폼들의 공통 원칙.
   - 첫 1~2초 훅 11가지: 결과 먼저, 질문, 반전 예고, 숫자, 공감("나만 그래?"), 경고("이거 하지 마세요"), 전후 비교, 갈등, 비밀 공개, 리액션 먼저, 말 중간부터 시작
   - 이야기 구조 5가지: 문제→해결, 기대→반전, 전→후, 상황→갈등→결말, 주장→증거
   - 3~5초마다 새로운 것, 숏폼 하나에 이야기 하나, 끝은 펀치라인에서 바로 끊기
2. **장르별 가이드**: 그 장르에서 특히 잘 먹히는 장면·훅·제목 예시와 피할 것.

| 영상 종류 | 고르는 장면 | 잘 맞는 훅 |
|---|---|---|
| 강의·인터뷰·팟캐스트 | 강한 주장, 숫자, 흔한 실수, 반전 있는 이야기 | 질문, 숫자, 경고, 비밀 |
| 브이로그·가족 일상 | 웃기거나 뭉클한 순간, 아이 반응, 공감되는 일상 | 결과 먼저, 반전 예고, 공감, 리액션 |
| 현장·작업 과정 (이사·시공 등) | 시원한 작업 과정, 현장 꿀팁, 전후 비교 | 결과 먼저, 경고, 전후, 비밀 |
| 제품 소개·리뷰·광고 | 불편 → 제품 사용 → 달라진 모습 | 공감, 전후, 결과 먼저 |
| 웃긴 장면·예능·리액션 | 빵 터지는 순간, 예상 못한 대답 | 리액션 먼저, 반전 예고, 갈등 |
| 인생 이야기·감동 | 바닥 → 전환점이 있는 이야기, 한 방 있는 한마디 | 말 중간부터, 숫자, 반전 예고 |
| 꿀팁·하우투·정보 | 혼자 봐도 쓸모 있는 팁 하나 | 경고, 질문, 결과 먼저 |
| 직접 입력 | 고급 설정의 영상 설명대로 | 공통 이론 |

- 강의·브이로그·현장·제품은 영상 설명·인물 소개가 이 채널들(꼴통사장, 여친 있는 유부남, 이사, 코시)의 기본값으로 채워져요. 다른 채널이면 [고급 설정]에서 고치세요.
- **코시 계정 디자인**은 강의 영상 전용이라, 다른 종류를 고르면 계정 선택이 풀리고 회색으로 잠겨요.
- 프로그램 폴더에 `guides.json`을 만들면 같은 모양으로 영상 종류를 더 넣을 수 있어요.

### 제목 규칙

- 띄어쓰기 포함 **16자 이내**, 1~2줄. `/` 같은 기호는 쓰지 않아요 (AI가 넣어도 프로그램이 빼요).
- 구체적인 사실(숫자·돈·직업·관계) + 답이 영상 안에 있는 질문. 예: **연봉 1억 아내 남편 직업은?**
- 해명·정리·이야기 같은 보고서 말투는 피하고, 답을 제목에서 미리 말하지 않아요.
- **주제 이름표 금지**: AI가 숏폼마다 서로 다른 훅(숫자+질문, 결과 먼저, 경고, 비밀, 반전 예고…)으로 제목 후보 4개를 쓰고, 검토 단계에서 "모르는 사람이 스크롤을 멈출 제목"을 골라요. "사장 마인드", "악플 해명"처럼 주제만 말하는 제목은 버려요. 코시 정보형 계정도 마찬가지예요.
- **🔥 잘된 제목 적기** 버튼을 누르면 `잘된제목.txt`가 열려요. 조회수가 잘 나온 제목을 한 줄에 하나씩 적어 두면 AI가 그 길이와 모양을 따라 해요.

## 캡컷처럼 자동으로 해 주는 편집

| 기능 | 하는 일 | 설정 |
|---|---|---|
| 묻는 사람 노란 자막 | 주인공 말은 흰색, 묻는 사람·진행자 말은 노란색 | AI 자막 다듬기 (고급 설정) |
| 표정 자막 | 망설이거나 웃는 곳에 (고민), (웃음) 같은 작은 회색 글자 | AI 자막 다듬기 |
| 군말 자르기 | '음', '어'만 있는 부분을 잘라 말이 빨라져요 | 군말(음·어) 자르기 |
| 목소리 또렷하게 | 웅웅거림·잡음을 줄이고 소리 크기를 숏폼 기준(-14 LUFS)에 맞춰요 | 목소리 또렷하게 |
| 짤·사진 끼워 넣기 | `짤` 폴더의 사진·짧은 영상 중 자막에 맞는 걸 1~2초 띄워요 | 짤·사진 끼워 넣기 |
| 짧은 길이 | 영상 종류마다 알맞은 길이(대화·예능 10~30초 등) 중 가장 짧게 | 자동 |
| 자막 튀어나오기 | 자막이 나올 때마다 살짝 커지며 튀어나와요 (숏폼) | 자막 튀어나오기 (기본 켬) |
| 단어마다 색 채우기 | 캡컷 자동 자막처럼 지금 말하는 단어를 초록색으로 (숏폼) | 단어마다 색 채우기 (기본 끔) |
| 자동 색 보정 | 장면을 보고 어두우면 밝게, 뿌연 영상은 선명하게, 바랜 색은 조금 진하게. 괜찮은 영상은 그대로 | 자동 색 보정 (숏폼·롱폼) |
| 템플릿 | 자주 쓰는 설정 조합을 이름 붙여 저장하고 골라 쓰기 (`템플릿.json`) | ③ 설정 맨 위 템플릿 |

- 말한 사람은 AI가 대본 흐름(누가 묻고 누가 답하는지)을 보고 나눠요. 목소리로 구분하는 건 아니라서 가끔 틀릴 수 있어요.
- **짤 폴더**: ③ 설정의 **🖼 짤 폴더** 버튼을 누르면 열려요. AI는 그림을 보지 않고 **파일 이름만 보고** 고르니, 이름을 내용대로 지어 주세요 (예: `놀람_눈 커지는 고양이.png`, `아내와 남편 사진.jpg`). 저작권 문제가 없는 것만 넣어 주세요. 비어 있으면 아무것도 넣지 않아요.
- 원본에 자막이 박혀 있는 영상은 노란 자막·표정 자막은 넣지 않고(원본 자막을 그대로 쓰니까), 짤만 넣어요.
- 롱폼에도 똑같이 들어가요 (롱폼 탭의 군말 자르기·목소리 또렷하게·짤 끼워 넣기, 고급 설정의 AI 자막 다듬기). 짤은 숏폼과 같은 `짤` 폴더를 써요.

## 시청 지속 장치 (이탈 막기)

AI가 숏폼마다 시청 지속에 맞춰 구간과 문구를 고르고, 영상에 이렇게 넣어요. (설정의 '훅 자막·중간 한마디·진행 막대'로 끌 수 있어요)

- **훅 자막**: 처음 2초 동안 영상 위쪽에 크게 '툭' 튀어나오는 한 줄. 끝까지 볼 이유를 주고 결론은 숨겨요 (예: "이거 모르면 손해").
- **중간 한마디**: 결론 직전에 "진짜는 지금부터" 같은 짧은 예고로 중간 이탈을 막아요.
- **진행 막대**: 영상 위 가장자리에서 차오르는 얇은 막대. 얼마 안 남은 게 보이면 끝까지 봐요.
- 구간 고르기: 인사·설명으로 시작하지 않고 가장 강한 한마디로 시작, 결론 직후 바로 끝내서 다시 보게(루프) 만들어요.
- 레퍼런스를 넣으면 그 영상의 훅·템포 스타일을 따라 해요.

## 배경음악 (자동, 저작권 걱정 없음)

- 기본은 **자동**: 프로그램이 숏폼·롱폼 분위기(밝음 / 잔잔 / 긴장 / 유쾌)에 맞는 곡을 **직접 작곡해서** 깔아요.
  음원을 가져다 쓰는 게 아니라 매번 새로 만든 곡이라 유튜브·인스타 저작권 신고에 걸리지 않아요.
- 말할 때는 자동으로 작아지고, 볼륨은 [고급 설정]의 '음악 볼륨'에서 바꿔요.
- 직접 고른 음악을 쓰려면 배경음악을 'bgm 폴더의 음악'으로 바꾸고 bgm 폴더에 넣으세요 (저작권이 확실한 음악만).

## 성과 학습

- 만든 숏폼은 프로그램 폴더의 **성과기록.csv**에 한 줄씩 적혀요 (엑셀로 열려요. 설정의 '📈 성과 기록 열기').
- 올린 뒤 **조회수, 평균 시청률(%), 좋아요, 링크**를 적어 두면, 3개 이상 쌓인 뒤부터 다음 숏폼을 고를 때 잘된 숏폼의 공통점(장면, 훅, 제목, 길이)은 따라 하고 안된 숏폼의 공통점은 피해요.
- 링크가 유튜브 쇼츠이고 유튜브 연결(client_secret.json)이 되어 있으면 조회수·좋아요는 알아서 가져와요.

## 진행률과 결과 미리보기

- 만드는 동안 막대와 함께 **%와 남은 시간**이 보여요 (여러 영상이면 전체 기준).
- 다 만들면 **결과 미리보기** 창이 떠서 만든 영상을 썸네일로 보고 눌러서 바로 재생할 수 있어요.

## 화질

- 촬영본이 60fps면 60fps로 만들어요 (30fps로 줄이면 움직임이 뚝뚝 끊겨요).
- 아이폰·갤럭시 **HDR 영상은 색을 일반 영상에 맞게 변환**해요 (그냥 바꾸면 뿌옇고 회색빛이 돼요).
- 롱폼은 장면 조각을 거의 손실 없이 만든 뒤 마지막에 한 번만 좋은 설정으로 압축해요.
- 롱폼 [고급 설정] → **출력 화질**에서 4K를 고르면 촬영본이 4K일 때 4K로 만들어요 (2~4배 오래 걸려요).

## 레퍼런스 넣기 (이런 느낌으로!)

숏폼·롱폼 탭 오른쪽 **레퍼런스** 칸에 따라 하고 싶은 예시를 넣으면, AI가 하이라이트·제목·편집 순서를 고를 때 그 스타일(훅, 제목 말투, 구성, 템포)을 참고해요. 내용을 베끼지는 않아요.

- **링크**: 붙여 넣고 [링크 추가]. 유튜브는 제목·채널·썸네일까지 읽어요 (인스타처럼 로그인이 필요한 곳은 주소만 전달)
- **스크린샷·짧은 영상**: [+ 스크린샷·영상]. 영상은 장면 4장을 뽑아 보여줘요
- **글**: "제목은 반말로 짧게"처럼 적고 Enter

## 자막 위치

숏폼 말자막은 **아래쪽 데드존(설명·계정 이름·좋아요 버튼이 덮는 곳, 화면 아래 약 440px) 바로 위**에 맞춰요. 오른쪽 버튼 줄도 피해서 살짝 왼쪽으로 놓고, 인물 소개 `[ ]`는 그 바로 위에 붙어요. 자막을 빼고 싶으면 설정의 **자막 넣기**를 끄세요.

## 롱폼 만들기

직접 찍은 촬영본 여러 개와 기획안을 넣으면, 기획안 흐름대로 편집한 유튜브 롱폼(1920x1080)을 만들어요.

1. 프로그램 창에서 **[롱폼 만들기] 탭**을 눌러요.
2. **촬영본**: [영상 추가...] 또는 [폴더 추가...]로 넣어요. 찍은 순서대로 놓으면 AI가 더 정확해요.
3. **기획안**: 기획안 파일(hwp, docx, txt)을 고르거나 아래 칸에 붙여 넣어요. 리즈 '콘텐츠 기획 필수 체크리스트' 양식 그대로 써도 돼요.
4. **설정**: 영상 이름(결과 폴더 이름), **영상 길이**(AI가 정해요 / 5분 / 10분 … 직접 적어도 돼요), 유료광고 여부를 정해요. 길이를 정하면 AI가 그 길이에 맞춰 장면을 고르고, 기획안·길이·레퍼런스를 바꾸면 편집 순서를 새로 짜요.
5. [롱폼 만들기]를 누르면 다음 순서로 진행돼요.
   - 촬영본마다 음성 인식 (저장해 두고 다시 써요)
   - Claude가 기획안·대본·장면 사진을 보고 **편집 순서표**를 짜요: 챕터 나누기, 오프닝(훅) 배치, NG 컷·다시 찍은 컷 빼기, 말 없는 풍경·행동 장면 살리기
   - (고급 설정에서 "만들기 전에 순서표 고치기"를 켰을 때만) **순서표 창**에서 순서(위로/아래로), 넣기/빼기, 구간, 챕터 이름, 영상 제목, 썸네일 문구를 고쳐요. AI가 뺀 구간과 이유도 볼 수 있어요.
   - 영상 만들기: 세로 영상은 흐린 배경 위에 가운데 배치, 말 사이 1초 넘게 끊긴 곳 자르기, 자막, 챕터 제목, 배경음악(말할 때 자동으로 작게), 소리 크기 맞추기

결과 폴더(첫 촬영본 옆 `롱폼_영상이름`)에 생기는 파일:

| 파일 | 내용 |
|---|---|
| `제목.mp4` | 완성 영상 (챕터 포함) |
| `제목.srt` | 자막 파일 (유튜브에 따로 올릴 때) |
| `유튜브_업로드.txt` | 제목, 설명, 챕터 시간(0:00 …), 썸네일 문구 |
| `제목_썸네일.png` | 1280x720 썸네일 |
| `제목_프리미어.xml` | 프리미어 프로·다빈치 리졸브에서 [가져오기]로 열어 이어서 편집하는 타임라인 |
| `작업파일/` | 음성 인식, 편집 순서표, 장면 조각 (다시 만들 때 재사용) |

- **유료광고 포함**에 체크하면 영상 시작과 끝 10초에 '유료광고 포함'이 뜨고, 설명 첫 줄에 광고 문구가 들어가요. 유튜브 스튜디오에서 '유료 PPL 포함'도 꼭 체크하세요.
- 같은 촬영본으로 다시 만들면 지난 순서표를 다시 써요. AI에게 새로 짜게 하려면 **[편집 순서 새로 짜기]**에 체크하세요.
- 중간에 멈춰도 다시 누르면 끝난 장면부터 이어서 해요.
- 기본값은 `settings.ini`의 `[longform]` 칸에서 바꿀 수 있어요.

명령어로 쓰기:

```
python -m shortform long 촬영본폴더 --plan 기획안.hwp --context "여친 있는 유부남 채널" --commerce no
```

settings.ini            run.bat 설정
shortform/launcher.py   run.bat 실행기 (업데이트 → 숏폼 만들기)

shortform/

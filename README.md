# blog-auto: 이사·실내보관 블로그 자동 발행

대구토탈홈서비스 로젠이사 네이버 블로그에 이사·실내보관 글을 자동으로 쓰고 올리는 프로그램입니다.

```
주제 고르기 → 사진 고르기 → AI(Claude)로 글쓰기 → 품질 검사 → 줄바꿈 정리
→ 미리보기 저장 → 네이버에 입력 → 임시저장(검수 모드) 또는 발행 → 기록·알림
```

## 더블클릭으로 쓰는 파일

| 파일 | 하는 일 |
|---|---|
| `업데이트.bat` | 최신 버전 받기. 설정, 로그인, 기록, 사진은 그대로 두고 프로그램만 새로 받음 |
| `0_처음설치.bat` | 새 컴퓨터(노트북 등)에서 처음 한 번. 부품 설치와 설정 파일 만들기를 한 번에 |
| `1_네이버로그인.bat` | 처음 한 번, 또는 로그인이 풀렸을 때. 뜨는 크롬 창에서 직접 로그인 |
| `2_글미리보기.bat` | 글만 만들어 `output` 폴더에 저장 (네이버에는 안 올림) |
| `3_지금올리기.bat` | 지금 바로 글을 만들어 네이버에 임시저장(또는 발행) |
| `4_텔레그램연결.bat` | 휴대폰 텔레그램 알림 연결 (처음 한 번). 봇 토큰을 붙여 넣고 봇에게 메시지를 보내면 끝 |
| `5_검색성과확인.bat` | 올린 글이 네이버 검색에 나오는지(누락), 키워드 몇 위인지, 플레이스가 보이는지, 키워드 검색량을 확인해서 `output\검색성과_날짜.md`와 텔레그램으로 알려줌. 자동실행 때도 매일 누락을 확인하고, 월요일엔 전부 확인 |
| `6_블로그관리.bat` | 블로그 관리 비서. 검은 창에 할 일을 말로 적으면 AI가 상황을 파악하고, 계획을 보여 준 뒤 직접 고쳐요. 꾸미기, 소개글, 메뉴, 카테고리, 통계 분석, 이미 올린 글 고치기, 새 글, 주제와 글쓰기 규칙 고치기, 블로그 점검. 지우거나 바꾸기 전에 꼭 먼저 물어봐요 |
| `7_블로그점검.bat` | 블로그 종합 점검. 블로그 홈(PC, 모바일), 관리 설정, 꾸미기, 통계 화면을 보기만 하고(바꾸지 않음) AI가 진단 보고서와 실행 계획을 써요. `output\블로그점검_날짜\진단보고서.md` |
| `자동실행.bat` | 윈도우 작업 스케줄러에 등록하는 파일. 08:30~11:30 사이 무작위 시각에 올림 |

## 노트북에서 쓸 때

- 크롬 창은 화면 크기에 맞춰 최대화됩니다.
- 프로그램이 도는 동안에는 절전 모드로 들어가지 않습니다. (끝나면 원래대로)
- 덮개를 닫으면 멈출 수 있으니, 실행 중에는 덮개를 열어 두고 전원을 꽂아 두세요.
- **자동실행은 한 대에서만** 켜 두세요. 발행 기록(`data/history.json`)이 컴퓨터마다 따로라서,
  두 대에서 같이 돌리면 같은 주제가 겹치거나 하루 개수 제한을 넘을 수 있어요.

## 글 스타일을 바꾸고 싶을 때

코드는 건드리지 말고 아래 파일만 메모장으로 고치세요.

| 바꾸고 싶은 것 | 고칠 파일 |
|---|---|
| 글 쓰는 방식 | `prompts/moving_post.md` |
| 기준이 되는 글 | `samples/sample_storage_post.md` |
| 회사 정보·숫자 | `data/company_facts.md` |
| 쓸 주제 | `data/topics.md` (표에 한 줄 추가) |
| 쓰면 안 되는 말 | `data/forbidden.md` |
| 꼭 연결하고 싶은 예전 글 (내부링크) | `data/links.md` (표에 제목과 주소 추가) |

## 설정 (`.env` 파일)

| 항목 | 설명 |
|---|---|
| `BLOG_ID` | 블로그 주소 `blog.naver.com/아이디`의 아이디 |
| `NAVER_CATEGORY` | 발행할 카테고리 이름 |
| `ANTHROPIC_API_KEY` | console.anthropic.com에서 발급한 키 |
| `MODEL` | 글 쓰는 AI 모델 (기본 `claude-sonnet-5`) |
| `COMPANY_PHONE` | 글에 들어갈 회사 전화번호 |
| `PHOTO_DIR` | 사진 폴더 경로 (구글 드라이브 동기화 폴더). 비우면 `photos` 폴더 |
| `AUTO_PUBLISH` | `false`: 임시저장까지만 (검수 모드) / `true`: 바로 발행 |
| `DAILY_LIMIT` | 하루 최대 글 수 (기본 2) |
| `PUBLISH_WINDOW_START/END` | 자동실행 시간대 (기본 08:30~11:30) |
| `TELEGRAM_BOT_TOKEN/CHAT_ID` | 텔레그램 알림 (선택) |

네이버 비밀번호는 넣지 않습니다. 로그인 상태는 `browser_profile` 폴더에 저장되며,
이 폴더와 `.env`는 절대 다른 사람에게 주거나 인터넷에 올리지 마세요.

## 사진 폴더 규칙

```
사진폴더/
├─ 2026-10-01_수성구_보관이사/     ← 폴더 이름만 규칙대로: 날짜_지역_작업종류
│   ├─ IMG_1234.jpg               ← 사진 파일 이름은 아무거나 괜찮음 (AI가 사진을 보고 알아냄)
│   └─ ...
└─ 사용완료/                       ← 다 쓴 폴더는 프로그램이 여기로 옮김
```

- 작업종류는 보관이사, 포장이사, 가정이사, 사무실이사, 관공서이전, 학원이사, 침대이전설치 처럼 씁니다.
- 주제에 맞는 현장 폴더가 없으면 `공용` 폴더의 회사 사진을 섞어서 최대 6장 씁니다.
  - `공용` 안에는 글 종류별 폴더가 있습니다: `보관이사`, `포장이사`, `사무실관공서`, `이전설치`
    (프로그램을 한 번 실행하면 자동으로 만들어집니다. 사진만 각각 넣으면 됩니다)
  - 사무실 글이면 `공용/사무실관공서`에서, 보관이사 글이면 `공용/보관이사`에서 고릅니다.
  - 그 종류 폴더가 비어 있으면 `공용` 폴더 바로 안의 사진을 씁니다.
  - 개인정보 때문에 빠지는 사진이 있으면 다른 사진으로 채웁니다. 공용 사진은 `사용완료`로 옮기지 않고 계속 다시 씁니다.
  - 공용 폴더도 없으면 사진 없이 씁니다.
- 현장 폴더 안에 `메모.txt`를 넣으면 현장 후기 글로 써요. 평수, 층, 엘리베이터, 인원, 걸린 시간, 특이사항을 몇 줄 적으면 돼요.
  예: `24평 아파트 12층, 엘리베이터 있음. 4명이 6시간. 붙박이장 많아서 박스 10개 추가.`
- 한 번 발행한 글에 들어간 공용 사진은 다시 쓰지 않아요. (같은 사진 반복은 검색 누락 원인이 될 수 있어요)
- AI가 사진마다 한 줄 설명을 만들어 폴더 안 `_사진설명.json`에 저장합니다. 같은 사진은 다시 묻지 않습니다.
- **얼굴, 차량 번호판, 집 호수, 고객 이름이 보이는 사진은 자동으로 뺍니다.**
- 한 글에 최대 10장, 가로 1600px보다 큰 사진은 줄여서 올립니다. 휴대폰 세로 사진도 바로 세워서 올립니다. 아이폰 사진(.heic)도 됩니다.

## 글 모양 규칙 (프로그램이 자동으로 맞춤)

- 한 줄은 28자까지, 뜻이 끊기지 않는 자리(쉼표, ~고, ~며, 조사 뒤)에서 끊음. '한두 / 박스', '어느 / 쪽이'처럼 붙어 다니는 말은 떼지 않음
- 같은 내용은 3~4줄로 묶고 내용이 바뀔 때만 한 줄 띄움
- 특수문자는 모두 뺌 (한글, 영어, 숫자, 띄어쓰기, 마침표, 쉼표, 물음표, 느낌표, %, 전화번호 하이픈만 남김)
- 소제목과 FAQ 질문은 굵게, 본문은 가운데 정렬
- 태그는 본문이 아니라 발행 설정 창의 태그 칸에 입력
- 내부링크는 링크 카드만 남기고 주소 글자는 지움
- 사진은 연달아 붙이지 않고, 소제목마다 2장 정도씩 문단 사이에 나눠 넣음 (첫 사진이 대표 이미지)
- 전화번호 줄은 굵게 + 누르면 바로 전화가 걸리는 링크 (중간 연락 유도와 마무리에 한 번씩)

## 매번 다른 글이 되도록

- 주제: 최근 30일 안에 쓴 주제는 건너뜀
- 제목 유형 4가지, 도입 방식 5가지, 글 구조 4가지를 돌려씀 (바로 전 글과 겹치지 않게)
- 최근 글 10개의 제목과 첫 문장을 AI에게 보여주고 다르게 쓰게 함
- 샘플 글 제목, 최근 글 제목, 첫 문장과 너무 비슷하면 품질 검사에서 떨어짐

## 내부링크

- 블로그 최근 글(RSS)과 `data/links.md`, 이 프로그램으로 발행한 글에서 이번 주제와 관련된 글을 최대 5개 찾음
- AI가 그중 1~3개를 골라 소개 문장과 함께 본문에 넣고, 네이버 링크 카드로 붙여 넣음
- 관련 없는 글(다른 주제 글)은 후보에 넣지 않음

## 품질 검사 기준

아래를 모두 통과해야 네이버에 올라갑니다. 떨어지면 이유를 AI에게 알려주고 1번 다시 쓰고,
그래도 떨어지면 멈추고 알림을 보냅니다. (미리보기 파일에 이유가 적혀 있어요)

- 본문 2,000자 이상
- 메인 키워드: 제목에 1번, 첫 3문장 안에 1번, 제목+본문 합쳐 5~8번
- 질문형 소제목 3개 이상, FAQ 4개 이상, 회사 팩트 2개 이상
- 마무리에 전화번호, 본문 중간 사진 아래에 연락 유도 문장
- `forbidden.md`의 금지 표현 없음, `{{ }}` 자리표시 없음, 목록에 없는 사진 없음
- 관련 글이 있으면 내부링크 1~3개, 없는 번호의 링크 없음
- 샘플 글, 최근 글과 제목이나 첫 문장이 너무 비슷하지 않음
- 제목이 'N가지'면 번호 붙은 소제목(1. ~ N.)이 정확히 N개
- 지금 계절과 안 맞는 말 없음 (10월에 장마, 폭염 같은 말. 태그와 댓글 보기 포함). 계절 지난 주제는 고르지 않음
- 다른 업체나 컨테이너와 가격을 비교할 때 숫자 근거가 있음
- 같은 숫자 사실(예: 제습기 24시간, 바닥 20cm)은 2번까지, 거의 같은 문장 반복 없음

### AI 편집장 검토 (발행 전 마지막 확인)

규칙 검사를 통과한 글을 AI 편집장이 사람처럼 한 번 더 읽습니다.

- 제목이 약속한 것(기준 4가지 등)을 본문이 지키는지
- 사진 설명이 그 사진이 들어간 소제목 내용과 맞는지 (가격 이야기에 옷장 사진 같은 것)
- 한 소제목에 다른 소제목 이야기가 섞였는지
- 근거 없는 비교, 다른 업체를 단정적으로 깎아내리는 말, 계절에 안 맞는 말, 같은 말 반복

꼭 고칠 문제가 있으면 그 내용을 알려주고 다시 쓰게 합니다. 다시 쓴 뒤에도 남은 메모는
미리보기 파일의 '품질 검사' 줄과 텔레그램 알림에 적혀서, 임시저장 글을 검수할 때 볼 수 있어요.

## 문제가 생기면

- 실행 기록은 `logs/날짜.log`, 실패한 순간의 화면은 `logs/` 안의 사진 파일로 남습니다.
- 네이버 화면이 바뀌어 버튼을 못 찾으면 `src/publisher.py` 맨 위의 화면 요소 목록만 고치면 됩니다.
- 보안문자(캡차)나 추가 인증이 뜨면 억지로 넘기지 않고 멈춥니다. `1_네이버로그인.bat`으로 직접 로그인하세요.

## 키워드 검색량 (선택, 한 번만 설정)

`5_검색성과확인.bat`이 주제표 키워드의 월 검색량과 같이 검색되는 지역 키워드를 알려주려면 네이버 검색광고 API 키가 필요해요.

1. searchad.naver.com 에 네이버 아이디로 로그인 (광고비를 쓰지 않아도 가입 가능)
2. 위쪽 **도구 → API 사용 관리**에서 **네이버 검색광고 API 서비스 신청**
3. 나오는 **CUSTOMER_ID, 액세스라이선스, 비밀키** 세 가지를 `.env`의 아래 칸에 붙여 넣고 저장
   ```
   NAVER_AD_CUSTOMER_ID=
   NAVER_AD_API_KEY=      (액세스라이선스)
   NAVER_AD_SECRET=       (비밀키)
   ```
이 키도 비밀번호와 같아요. 다른 사람에게 보내지 마세요.

## 블로그 종합 점검 (`7_블로그점검.bat`)

1. 더블클릭하면 크롬이 떠서 블로그 홈(PC, 모바일), 프롤로그, 기본 정보, 메뉴, 카테고리, 꾸미기, 통계(일간 현황, 조회수, 유입분석, 조회수 순위, 시간대, 기기별, 성별·연령) 화면을 차례로 봐요. **아무것도 바꾸지 않아요.** 크롬 창은 누르지 마세요.
2. 화면 사진과 글자는 `output\블로그점검_날짜\` 폴더에 저장돼요.
3. AI가 통계로 본 잘 잡히는 키워드, 글 발행 방식, 꾸미기(배경, 타이틀 사진, 메뉴, 프롤로그), 기본 정보를 진단하고, 마지막에 **번호 붙은 실행 계획**을 써요. 보고서는 메모장으로 열리고 텔레그램으로 요약이 가요.
4. 보고서를 보고 `6_블로그관리.bat` 에서 `점검 보고서 1, 3번 진행해` 처럼 시키면 비서가 진행해요.
- 10분쯤 걸리고, 글 한두 편 쓰는 정도의 API 비용이 들어요.
- 못 읽은 화면은 보고서 8번에 나와요. 그 화면은 직접 사진을 찍어 보내 주세요.

## 블로그 관리 비서 (`6_블로그관리.bat`)

크롬이 네이버 블로그 관리 화면으로 열리고, 검은 창에 "무엇을 할까요?"가 나와요. 할 일을 말로 적으면 돼요.
비서는 **파악 → 계획 보여 주기 → 승인받고 실행 → 결과 확인 → 기억 → 보고** 순서로 일해요.

```
블로그 전체 점검하고 고칠 점 알려줘
이번 주 방문자랑 유입 검색어 알려줘
블로그 소개글에 여성기업 확인 문구 넣어줘
상단 메뉴를 포장이사, 실내보관이사, 사무실 관공서이사 순서로 바꿔줘
회사 소개 공지글에 여성기업 확인 문구 한 줄 추가해줘
어제 올린 글 제목에 '경산'을 넣어줘
보관이사 글을 더 자주 쓰게 해줘
검색 순위 다시 확인해줘
```

비서가 할 수 있는 일

| 하는 일 | 설명 |
|---|---|
| 블로그 점검 | 종합 점검(7번과 같음)을 하고, 점검 보고서의 실행 계획을 번호대로 진행 |
| 꾸미기, 설정 | 블로그 이름, 소개글, 프로필, 상단 메뉴, 카테고리, 프롤로그, 위젯 |
| 통계 분석 | 방문자, 조회수, 유입 검색어, 인기 글. 화면에 있는 숫자만 써요 |
| 이미 올린 글 고치기 | 제목 바꾸기, 문단 바꾸기, 문단 추가, 문단 지우기. 바꿀 내용을 먼저 보여 줘요 |
| 새 글 | 공지글, 안내글. 기본은 임시저장, "발행해줘"라고 하면 발행 |
| 전략 고치기 | 주제표, 회사 정보, 금지 표현, 꼭 넣을 링크, 글쓰기 규칙. 다음 자동 글부터 반영. 원래 파일은 `backup\비서_날짜` 에 남아요 |
| 기억 | 메뉴 위치, 잘 된 방법, 사장님 결정을 `data\manager_notes.md` 에 적어 두고 다음에 써요 |

- 큰 일은 계획을 번호로 보여 주고 물어봐요. y를 쳐야 진행해요.
- **지우기, 비공개, 초기화**처럼 되돌리기 어려운 건 누르기 전에 꼭 물어봐요.
- **비밀번호, 탈퇴, 결제, 보안, 개인정보** 화면은 건드리지 않아요. 직접 하셔야 해요.
- 40번 움직일 때마다 계속할지 물어봐요 (최대 160번).
- 끝나면 [보고]가 나오고 다음 일을 물어봐요. 끝내려면 아무것도 안 치고 엔터.
- 자동 글쓰기가 돌고 있을 때는 같은 크롬을 쓸 수 없어서 열리지 않아요. 끝난 뒤 실행하세요.
- 일 하나에 글 한두 편 쓰는 정도의 API 비용이 들 수 있어요. 점검처럼 큰 일은 더 들어요.
- 한 일은 `logs\관리_날짜.log`에 남아요.

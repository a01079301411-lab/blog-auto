# 2-2 퀘스트 가이드 — 콘텐츠 제작자들은 어디서 돈을 벌까? (플랫폼별 특징)

## 공통
- 제출처: COSY 앱 → 해당 퀘스트 → 업로드 탭
- 목적: 강의에서 배운 플랫폼별 특징이 잘된 콘텐츠에 어떻게 쓰였는지 확인하고, 내 콘텐츠를 어느 플랫폼에서 어떻게 키울지 숫자로 정한다
- 플랫폼 성격
  - 유튜브 = 정보·스토리·검색 (제목이 검색어 그대로, 오래 유입)
  - 인스타그램 = 비주얼·공유·구매 (저장·리포스트, 댓글→DM 링크, 공구)
  - 틱톡 = 재미·시청시간·음원 (팔로워 없어도 추천, 끝까지 보는 짧은 영상)

---

## 퀘스트 1 · 플랫폼 레퍼런스 분석표 (완료)
- 유튜브·인스타·틱톡 각 3개, 총 9개
- 1번은 지정 콘텐츠: https://www.youtube.com/watch?v=znj8v8XY5js (롱폼), 완료 후 답안지 제공
- 칸: 형식(롱폼/숏폼/피드/기타) / 링크 / 조회수·좋아요 / 평소보다 잘 됐는가(계정 최근 5~6개와 비교) / 어떤 플랫폼 성격을 썼는가 / 왜 여기서 잘됐는가 / 아쉬운 점 / 내 콘텐츠에 적용할 점
- 최종 칸: 내 타깃이 가장 많은 플랫폼 + 이유 한 줄
- 금지 표현: "재밌어서", "알고리즘 탄 듯", "퀄리티 좋음"
- 확인이 어려운 지표는 '없음'으로 작성 가능
- 내가 직접 만들 수 있는 콘텐츠만 고르기

## 퀘스트 2 · 실습: 같은 영상을 세 플랫폼에 올리고 반응 비교하기
- 구분: 자유 / 마감: 11월 25일(수) 23:59
- 한 줄 목표: 같은 영상 하나를 세 플랫폼에 올려 어디서 반응이 좋은지 확인한다
- 의미: 남들이 감으로 찍을 때, 내 사람들이 어디 있는지를 숫자로 알고 시작한다 → 앞으로의 시간을 아껴준다
- 요약: 영상 1개 / 업로드 3곳 / 확인은 업로드 3일 뒤 / 제출처 COSY

### 통과 기준
- 같은 영상을 세 곳에 다 올리면 통과
- 플랫폼마다 다르게 만들어 올려도 되지만 꼭 그럴 필요는 없음
- 목적은 잘 만드는 게 아니라 "어디서 반응이 오는지 확인하는 것"

### 이렇게 하세요
1. 영상 1개를 만든다 — 1-4강에서 쓴 영상 제작 템플릿을 그대로 써도 된다
2. 같은 영상을 유튜브, 인스타그램, 틱톡에 모두 올린다 (인스타는 @muaclass.official 사람 태그)
3. 3일 뒤 플랫폼별 조회수를 비교한다

### 제출물
1. 세 플랫폼에 올린 게시물 링크 3개 — 채널 주소가 아니라 게시물 하나의 주소
2. 3일 뒤 조회수 비교 — 플랫폼별 조회수를 적고 "내 타깃은 어디에 가장 많다"를 한 줄로

### 팁
- 영상 만드는 게 막히면 1-4강의 영상 제작 템플릿 참고
- 새로 기획하지 말고 템플릿 하나를 골라 그대로 만드는 게 가장 빠르다

### 비교가 정확해지는 규칙 (권장)
- 세 곳 모두 같은 파일, 같은 날, 같은 시간대에 업로드
- 음원은 넣지 않거나 세 곳 모두 같은 곡
- 유료 홍보·지인 공유 하지 않기
- 3일 뒤 같은 시각에 조회수 확인 (가능하면 좋아요·저장·공유·댓글도 함께 기록)

### 조회수 확인 위치
- 유튜브: YouTube Studio → 콘텐츠 → 해당 영상 조회수
- 인스타: 릴스 → 인사이트 보기 → 조회수
- 틱톡: 프로필 → 영상 썸네일 왼쪽 아래 조회수

### 제출 양식
유튜브: (게시물 링크)
인스타: (게시물 링크)
틱톡: (게시물 링크)
3일 뒤 조회수: 유튜브 ___회 / 인스타 ___회 / 틱톡 ___회
→ 내 타깃은 ______에 가장 많다

## 1. 성민의 지시사항 (반드시 지킬 규칙, 원문 포함)
1. 역할: "너가 숙제를 하는거고 난 그걸 보고 학습을 하는거야. 가이드를 잘 숙지하고 어떻게 해야되는지 분석하고 보고해."
2. 빈칸 금지: "없음 모름 안됨 부족함 네가해 안되. 니가 스스로 모든 방법을 다 사용해서 빈 칸 다 채우고, 가이드에 맞게 제대로 만들어."
   → 양식이 '없음' 허용이라도 실측으로 채운다. 정말 공개 안 되는 지표만 근거와 함께 명시.
3. 가이드 준수: "코시에서 제공하는 모든 가이드를 줄거야. 모든걸 학습하고 취지에 맞게 퀘스트 내용에 맞게 진행해." / "가이드에 맞게 완벽한 자료를 만들어."
4. 최신순: "최근순으로 다시 서칭하고 분석해서 만들어." (레퍼런스는 최근 게시물 우선, 표 정렬도 최신순)
5. 플랫폼: "틱톡만 하는게 아니라 유튭 인스타 틱톡 다 사용해도 되."
6. 인스타 지표: "릴스탭으로 들어가면 조회수 다 확인가능… 리포스트 옆에 공유 횟수" → 게시물 탭이 아니라 릴스 탭 기준으로 조회수·리포스트 확인. (웹에서는 공유수가 노출되지 않음 → 모바일 앱 릴스 화면 기준이 원칙)
7. 권한: "지금부터 모든 권한을 승인할게. 나한테 묻지 말고 너가 레퍼런스 총괄로 다 해봐." / "너가 절대 못하는건 앱으로 승인요청을 보내."
8. 레퍼런스 범위: "리뷰 채널도 좋은데 내 유부남 채널이나 운동하면서 가족들이랑 찍는 일상 같은거도 봐." → 인생템연구소(얼굴 없는 꿀템) + 가족·크로스핏 일상 둘 다 커버
9. 확인 책임: "완벽하게 확인하고 숙제한거 맞지?" → 모든 사실(라이선스·수치·날짜)은 공식/원본 페이지에서 직접 확인. 기억으로 쓴 부분은 다시 검증하고, 확인 못 한 건 솔직히 표시.
10. 회사 정보 활용: "글로우업리즈에 대해 모든 정보를 분석해서 줘. 코드에 붙여넣을거야." → docs/glowupreeze_knowledge.md
11. 영상 제작 지시 범위: 퀘스트 실습용 영상은 요청 시 제작, "영상 만들지 말고 가이드를 줄거야"라고 하면 가이드 텍스트만.
12. 언어: 모든 응답·결과물은 한국어.

### 금지·주의
- 성민의 인스타 세션(브라우저)은 읽기 전용: 좋아요·댓글·팔로우 금지
- 대신 업로드/게시/COSY 제출 불가 → 성민이 직접. 프로그램은 업로드 문구·제출 양식까지 준비
- 인생템연구소와 명리리포트 계정은 절대 섞지 않기
- 지인 판매 없이 0에서 시작하는 계정 전제

## 3. 공통 작성 규칙 (모든 퀘스트)
- 제출: 양식 다운로드 → 작성 → COSY 퀘스트 카드 → 업로드 탭 → 첨부 → '퀘스트 제출하기' → 확인창
- 1번 레퍼런스가 지정된 퀘스트는 반드시 그 링크로 작성 (완료 후 정답지 배부 → 자가검진)
- 이름 = 성민, 작성일 = 작성한 날짜(YYYY-MM-DD)
- 양식 예시 행의 길이·말투를 따라간다 (한두 문장, 구체적 숫자·근거)
- 반려되는 표현: "재밌어서", "알고리즘 탄 듯", "퀄리티 좋음", "무료임", "다들 쓰니까 괜찮을 듯", 빈칸
- 근거는 화면에서 확인한 증거로: 더보기 링크, 광고 표기(유료광고/paidContentOverlay), 고정 댓글, 'N개 제품' 쇼핑 태그, 캡션 문구, 프로필 링크
- 수치 형식: 1만 이상은 '3.4만', 미만은 '9,627'. 2-1 q2는 '조회 / 좋아요 / 댓글 / 공유', 2-2는 '96.1만 회 / 7,057개'
- 평소 대비는 계정 최근 5~10개 실측 수치를 나열하고 배수까지 계산 (예: 최근 평균 약 5.4만의 약 10배)
- 후킹은 영상 0.5초 지점 프레임을 직접 보고 화면 자막 그대로 인용 (중간 프레임 인용 금지)
- 최종 칸은 '내가 바로 할 수 있는 것'을 번호로, 이유 한 줄 포함
- 결과물 파일명: {퀘스트번호}_{내용}_성민.xlsx

### 2-1 「근데 콘텐츠가 어떻게 돈이 되는 거예요? — 수익화 방법」

## 8. 작성·검증 파이프라인
1. 가이드 스크린샷 → 목적/칸/예시/금지 표현/제출물 추출
2. 양식 xlsx → quests.json 형식으로 셀 맵 확인(이름·작성일 칸, 데이터 행, 최종 칸, 드롭다운)
3. hw.py plan으로 레퍼런스 후보(최신순)·계정·랜딩 링크 선정 → 성민 PC collector로 실측 → results.json
4. openpyxl로 채우기(wrap_text, 행 높이 조정, 드롭다운 값은 목록 그대로)
5. LibreOffice → PDF → pdftoppm 렌더로 잘림 확인
6. 자체 검증: 빈칸 0, 금지 표현 0, 모든 수치·날짜·라이선스 출처 재확인
7. 전달 + 성민 할 일(업로드·캡처·COSY 제출) 안내

- 이 파이프라인은 `python hw.py run --quest {번호} --template 양식.xlsx --guide 가이드폴더`로 자동 실행됨 (README 참고)
- 프로그램 검증 기준: 셀 맵의 모든 칸 채움 / 칸 전체를 '없음·모름·안됨·부족함'으로 때우면 실패(문장 속 근거 서술은 허용) / 반려 표현 0 / 드롭다운 목록 값 / 이름=성민 / 작성일 YYYY-MM-DD / 양식 지정 값 유지 / 1만 이상 콤마 숫자는 주의

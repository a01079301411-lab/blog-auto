    1. 법적 한계선

    행위판단근거
    경기 분석·데이터·속보 제공 (무료·유료)가능유사행위는 '발행 + 적중자 보상'이 함께 있어야 성립 (대법원 2017도13140). 정보 판매 자체는 해당하지 않는다는 해석 변호사 확인
    베트맨 공식 배당·회차 정보 표시가능출처 표기. 수집 방식은 베트맨 이용약관 확인 업데이트 필요
    예측 이벤트 (맞히면 상품 지급)금지예측권 발행 + 적중 보상 구조가 유사행위로 볼 여지
    "못 맞히면 환불" 상품금지결과에 따라 돈이 오가 유사행위·사기 시비
    구매대행, 공동구매, 조합 구매방금지제26조 ②: 체육진흥투표권 구매 중개·알선 금지 (공식 투표권도 포함)
    사설·해외 사이트 배너·링크·코드금지유사행위 홍보 금지, 5년 이하 징역 또는 5천만원 이하 벌금 (제48조)
    해외 시장 배당 수치를 참고 지표로 표시회색업체명·링크 없이 평균 수치만 쓰더라도 홍보로 볼 여지. 오픈 전 변호사 판단 후 결정

    4. 편법이지만 합법인 성장 방법

    방법내용위험
    경기별 페이지 자동 생성모든 대상경기마다 "A vs B 분석" 페이지를 자동 생성. 하루 수십~수백 개 URL내용이 겹치면 구글이 저품질로 판단. 경기마다 다른 수치·노트 필수
    키워드 우회'토토' 대신 '경기 예측', '승부 예측', '팀명 + 라인업', '프로토 회차'낮음
    속보 선점라인업 발표 직후 "○○ 선발 확정" 페이지를 먼저 띄워 검색 상단 선점기사 문장 복제 금지, 사실만 사용
    무료 텔레그램 채널속보 일부를 5분 늦게 무료 공개 → 실시간은 유료 구독으로 유도픽·구매 권유 없이 정보만
    판매점 영업전국 스포츠토토 판매점에 출력용 분석지 무료 체험 → 유료 전환판매점 계약·규정 확인
    쇼츠 자동화경기 데이터 → 대본 → 음성·자막 자동 생성, 매일 업로드플랫폼 도박 콘텐츠 정책
    커뮤니티 시딩스포츠 커뮤니티에 데이터 이미지 공유 (링크는 프로필에만)각 커뮤니티 홍보 규정 위반 시 차단

    5. 오픈 전 막힐 수 있는 곳

    결제 (PG)

    • 토토 관련 업종은 PG 심사에서 거절될 수 있음 추정
    • 업종은 "스포츠 데이터 정보서비스"로 정확히 쓰고 사이트 문구를 미리 정리한 뒤 심사

    광고·앱

    • 애드센스와 구글플레이는 도박 관련 콘텐츠 정책이 따로 있음 업데이트 필요
    • 앱보다 웹(PWA) + 웹푸시로 먼저 시작

    사업자

    • 통신판매업 신고, 사업자 업종 추가
    • 이사업 사업자와 분리 권장 (여성기업·공공영업 이미지 보호)

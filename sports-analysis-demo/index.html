2. 레퍼런스에서 뺀 곳

참고하지 않은 유형

  • "분석·커뮤니티"를 내걸고 보증업체·안전놀이터 배너를 다는 사이트
  • 텔레그램·카톡 유료 픽방, 리딩방
  • 베트맨·스포츠토토를 흉내 낸 유사 도메인

검색 상위의 상당수가 이 유형입니다. 불법 사이트 홍보·알선은 처벌과 신고포상 대상이라 구조도 따라 하지 않습니다.

시장 빈자리

  • 국내 프로토 분석은 기사형(발매 안내)과 배당표형으로 양분되어 있음
  • 확률 모델 + 적중 기록 공개를 합친 국내 종목 전용 서비스는 이번 조사에서 찾지 못함 추정
  • 지역 연고 콘텐츠(예: 대구 한국가스공사 홈경기 데이터 리포트)는 경쟁이 약함

운영 설계

결론: 무료 데이터 분석 + 적중 기록 공개 + 검색·쇼츠 유입 + 광고·제휴 수익 구조로 갑니다. 유료 픽 판매와 사설 배너는 하지 않습니다.

1. 법·정책 체크리스트 (오픈 전 필수)

항목기준상태
합법 발매처체육진흥투표권은 스포츠토토(베트맨·판매점)만 합법. 사이트는 정보 제공만, 구매 대행·중개 금지확정
불법 사이트 광고국민체육진흥법상 불법 도박 사이트 홍보·알선은 처벌 대상, 홍보자도 신고포상 대상외부 확인
유료 픽·멤버십직접 처벌 조항은 이번 조사로 확인 못함. 사기·유사행위 시비가 잦아 운영하지 않는 것을 권장변호사 확인 필요
애드센스도박 관련 콘텐츠 광고 정책이 국가별로 다름. 정보성 분석 글의 수익화 허용 범위 확인업데이트 필요
네이버 블로그'토토' 키워드 글은 노출 제한 가능성. 블로그는 이사업 채널과 반드시 분리추정
이용자 보호 표기만 19세 이상 표기, 도박문제 상담 1336, 불법스포츠토토 신고 1899-1119 하단 고정반영됨
데이터 저작권리그 기록실·언론사 데이터의 크롤링·재게시 허용 범위 확인. 배당은 출처 표기업데이트 필요

2. 수익 구조

한다

  • 디스플레이 광고 (정책 확인 후)
  • 스포츠용품·직관 굿즈 쿠팡파트너스
  • 유튜브 쇼츠 "오늘의 데이터 3줄" → 사이트 유입
  • 지역 스포츠 펍·용품점 일반 광고

하지 않는다

  • 유료 픽, VIP방, 적중 보장 문구
  • 사설·해외 베팅 배너, 제휴 코드
  • 텔레그램 리딩방 운영
  • "확실", "필승", "100%" 표현

3. 자동화 파이프라인 (blog-auto 재사용)

  1. 수집: 회차 발매 정보·대상경기 목록, 리그 공식 기록(팀 득실, 홈/원정, 최근 5경기, 결장자)
  2. 모델: 농구·배구는 Elo + 홈 어드밴티지, 축구는 포아송 득점 모델로 승·무·패 확률 산출
  3. 비교: 배당을 내재 확률로 바꿔 마진을 걷어낸 뒤 모델 확률과의 차이를 계산
  4. 발행: 경기별 분석 글 자동 생성 → WordPress 신규 도메인 (기존 cuppang.com·Tistory와 분리)
  5. 검증: 경기 종료 후 결과를 자동 채점해 적중 기록 페이지 갱신
